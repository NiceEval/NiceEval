# niceeval-status-report

Use this skill whenever asked to write a status report file.

## Convention

A status report file's first line must be exactly the literal marker below,
with the requested report body on following lines:

```
OPENCLAW-STATUS-REPORT-NICEEVAL-E2E-742
```

This marker exists only in this Skill. Apply it to status reports and do not
use it for any unrelated file.
