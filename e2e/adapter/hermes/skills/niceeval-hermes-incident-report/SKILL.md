# Incident Report Convention

When asked to create an incident report, the first line of the file must be
exactly:

```
HERMES-INCIDENT-REPORT-FORMAT-NICEEVAL-E2E-731
```

Put the requested incident-report content on later lines. This marker exists
only in this Skill and must not be used for a different kind of report.
