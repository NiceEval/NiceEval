Record 保存 Run、Attempt、Attachment、Content 和 Seal。项目里的 operational Store 位于 `.niceeval/record/record.sqlite`，可同时包含正在写入和已经发布的运行事实。

只有 sealed Run 可供 Inspection、`query` 和 `view` 读取。发布后的事实不可修改。缓存、凭据、协调状态和 OS-user Service state 不属于 Record。

## Snapshot 是唯一的可携带读取输入

```sh
niceeval record snapshot --output ./snapshots/baseline.record-snapshot
niceeval query discover --record ./snapshots/baseline.record-snapshot
niceeval view --record ./snapshots/baseline.record-snapshot
```

Snapshot 命令清除未发布 closure，验证 exact Seal，然后发布 sealed-only artifact。普通 SQLite copy、WAL、checkpoint 文件和任意外部文件都不能代替 Snapshot。

Snapshot 固定 exact Seal。`query` 与 `view` 使用它时不会隐式迁移、watch 或 refresh。Snapshot 仍可能包含敏感业务内容；分享者负责权限、脱敏和保留策略。

## 读取边界

Record 不负责统计、比较或页面。固定 Inspection operation 读取封口事实后，才把闭合的结果交给 `query` 或第一方 `view`。读取路径不能把数据库、reader、Content handle 或 SQL 能力交给外部代码。

查看 [CLI](/zh/reference/cli) 选择读取方式。
