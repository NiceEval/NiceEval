# NiceEval

**给 AI Agent 和 AI 应用写评估，像写单元测试一样顺手**

</div>

你改了 prompt、换了模型、给 Coding Agent 写了一个新 Skill，或者调了 LLM 游戏里的 NPC，想知道它到底有没有变好。NiceEval 让你用 TypeScript 写下“什么算做对”，然后反复运行、打分、比较，并回到每一次失败去看 Agent 实际做了什么。

所有运行都在你自己的机器和 CI 里完成，不需要注册账号。

## 常见问题

<AccordionGroup>
  <Accordion title="需要注册账号吗？">
    不需要。运行评估和查看结果都在本地完成。只有被测对象需要隔离环境时，才会用到 Docker 或 E2B 这类 Sandbox Provider。
  </Accordion>
  <Accordion title="我的 Agent 不是用 TypeScript 写的，能接吗？">
    能。评估用例和 Adapter 用 TypeScript 写，被测应用可以是任何语言。Adapter 只是通过 HTTP、gRPC 或 WebSocket 请求应用已有的接口，见 [Adapter](/zh/explanation/adapter)。
  </Accordion>
  <Accordion title="能接到 CI 里吗？">
    能。在 CI 里运行同一条 `niceeval exp` 命令，退出码反映评估是否通过，见 [CI 集成](/zh/tutorials/ci-integration)。
  </Accordion>
</AccordionGroup>
