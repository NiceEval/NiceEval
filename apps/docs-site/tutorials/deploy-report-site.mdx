Generate the complete report site first, then deploy the output directory. The hosting platform never reads the source Record and does not need NiceEval installed or running.

```sh
pnpm exec niceeval view --experiment checkout \
  --out ./report-site \
  --no-open
```

To deploy one explicit Run, read its Run ID from the receipt:

```sh
pnpm exec niceeval view --run <run-id> --out ./report-site --no-open
```

## CI workflow

A static-hosting workflow has three steps:

1. Run the Experiment and retain the final receipt.
2. Build the complete site with `view --out`.
3. Upload the output directory, not the source Record.

Example build steps for GitHub Actions:

```yaml
- name: Generate report site
  run: pnpm exec niceeval view --experiment checkout --out ./report-site --no-open

- name: Upload static site directory
  uses: actions/upload-pages-artifact@v3
  with:
    path: ./report-site
```

## Check before publishing

Before export, NiceEval validates every explicitly declared regular Page, parameterized Page instance, link, asset, download, `_niceeval/data/projections.json`, and budget in `pages`; the Host does not invent detail routes. A successful directory contains HTML, Report CSS, the reload client, author assets, downloads, and projections. The projection bytes are part of revision identity; the client quietly disables reload when a static directory has no reload endpoint.

Before deploying, disconnect the network while keeping bundled JavaScript enabled, then open the home page and at least one parameterized detail page. The body, navigation, completeness, problems, and downloads must remain readable. Disable JavaScript separately and confirm the explicit enable-JavaScript error. When local `view` uses the same selection and Report, the HTTP body for a route and its directory-page body must be byte-for-byte identical.

`--out` must point to a directory that does not exist. To update content, select a new Sample, export to a new directory, then switch the hosted release version. Do not overwrite the old directory.
