# Experiment 对账 —— 用例

按改动来源选择场景。EvidenceRequirement、默认沿用边界与对账阶段以
[Architecture](../architecture.md) 为准。

| 改了什么或想做什么 | 用例 |
|---|---|
| 隧道 URL、临时实例地址轮换 | [轮换连接坐标](轮换连接坐标.md) |
| 清空或更换被测服务的起点状态 | [归零被测服务状态](归零被测服务状态.md) |
| SandboxSpec Hook 里的预置命令 | [修改Sandbox预置](修改Sandbox预置.md) |
| agent 工厂的开关参数 | [修改Agent工厂参数](修改Agent工厂参数.md) |
| 格式化源码,或改不参与判定的代码 | [格式化源码](格式化源码.md) |
| eval 要读一个数据文件 | [读入数据文件](读入数据文件.md) |
| 跨 Run 对照被口径变更切断 | [跨Run对照](跨Run对照.md) |

每篇固定回答三件事：场景怎样声明、默认计划沿用还是派发、人工覆盖的边界在哪里。
