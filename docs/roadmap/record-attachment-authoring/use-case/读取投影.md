# 安装、读取与领域投影

Record host 安装 SDK 导出的 opaque capability：

```ts
export default defineConfig({
  recordAttachments: {
    install: [measurementRecordInstallation],
  },
});
```

installation 允许 reader exact-match family，并允许 maintenance 使用 adapter 自有 graph。它不能构造 binding 或取得
producer session。

领域 SDK 用私有 projector 包装 Analysis API：

```ts
export const projectMeasurement = (sampleHandle: AnalysisSampleHandle) =>
  projectAnalysisSample({
    sampleHandle,
    projection: measurementByAttempt,
  });
```

普通 Analysis 只调用：

```ts
const projected = yield* projectMeasurement(sampleHandle);
```

结果保留每个 logical slot、Sample denominator、issues、refs 与 Attachment 六态。SDK 可以隐藏 schema、reader、payload
和 blob closure，但不能只返回 available values。

普通 read 不迁移。known old 返回 `migration-required`；unknown family 返回 `unsupported`；invalid bytes 保持
`invalid`。I/O 与 permission failure 留在 Effect error channel。
