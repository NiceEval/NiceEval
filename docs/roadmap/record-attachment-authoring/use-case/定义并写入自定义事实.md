# 领域 SDK 定义并生产自定义事实

普通 Eval 作者不应知道 schema、owner、write grant 或 Record command。领域 SDK 把这些机制封在 adapter 与 Plugin
内部，再向 Eval 暴露领域配置。

## SDK 内部

```ts
const measurementRecord = defineRecordAttachmentAdapter({
  owner: "attempt",
  name: "com.example.measurement",
  versions,
  current: "v2",
  migrations,
  adapt: (measurement, target) =>
    Effect.succeed(target.value(toPayloadV2(measurement))),
  project: ({ payload }) => toMeasurementView(payload),
});

export const measurement = definePlugin<MeasurementOptions>({
  name: "com.example.measurement",
  behaviorRevision: "2",
  eval({ meter }) {
    return {
      recordAdapters: {
        attempt: [
          defineAttemptRecordAdapterBinding({
            adapter: measurementRecord,
            behaviorIdentity: meter.behaviorIdentity,
            open: meter.open,
            seal: meter.seal,
            release: meter.release,
          }),
        ],
      },
    };
  },
});
```

binding 对每个 actual Attempt 是 total obligation。meter 返回 sealed domain value；host 随后 adaptation 并提交一次
canonical command。

## 普通 Eval

```ts
export default defineEval({
  plugins: [measurement({ meter: deviceMeter({ device: 0 }) })],
  async test(t) {
    await t.send("完成任务");
    t.succeeded().label("任务完成");
  },
});
```

Eval 没有 `recordAttachments.write` 或 `record()`。完整 GPU 版本、迁移、读取与 Report 见
[第三方 GPU 完整路径](../../record-analysis-report/use-case/第三方事实扩展.md)。
