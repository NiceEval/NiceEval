# 定义并写入自定义事实

一个 Eval 要保存实际测得的 GPU 能耗。这个值运行前未知，因此不写进 flags；它是 Attempt-owned
RecordAttachment。

```ts
import { Schema } from "effect";
import { defineEval } from "niceeval";
import { defineRecordAttachment } from "niceeval/record";

export const gpuEnergy = defineRecordAttachment({
  owner: "attempt",
  name: "com.example.gpu-energy",
  versions: {
    v1: {
      schema: Schema.Struct({
        joules: Schema.Number,
        source: Schema.Literal("device-estimate"),
      }),
      blobRefs: () => [],
    },
  },
  current: "v1",
  migrations: () => ({}),
});

export default defineEval({
  recordAttachments: [gpuEnergy],
  async test(t) {
    const joules = await measureGpuEnergy();

    await t.record(gpuEnergy, {
      joules,
      source: "device-estimate",
    });
  },
});
```

definition 冻结 payload 语义；allowlist 授权这个 Eval occurrence 写入。形成 payload 的算法变化仍进入 Eval
behavior identity；需要这份 Attachment 才能 carry 时，Eval 的 reuse contract 另行声明 requirement。
`t.record()` 只接收 allowlist 中的 Attempt definition，同一 family 第二次调用会失败。

应用另行安装 definition，供历史读取与 migrate 使用：

```ts
export default defineConfig({
  recordAttachments: [gpuEnergy],
});
```

该 registration 不授予其它 Eval 写入。Report 需要 typed view 时另定义 neutral projector；它不进入 writer 或
migration definition。
