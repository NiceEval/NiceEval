# 交接 Sandbox、Agent 与 Adapter 观测

Sandbox provider、Agent 与 Agent Adapter 不是 durable Record owner。它们只返回 typed observation 或把事件交给当前
领域 collector；不接收 root、writer、binding 或 owner lease。

```ts
const session = yield* agentRuntime.open({ attempt, signal });
const observation = yield* session.run(input);
yield* collector.accept(observation);
```

领域 producer 的 child Scope 持有 `collector`。多次 observation 可以在这里累积、去重并验证完整性；owner seal 时只
形成一份 sealed domain value：

```ts
seal: (session, context) =>
  session.collector.seal(context.exit),
```

RecordAttachment adapter 只在 release 成功后接收这份 sealed value。它不成为事件日志，也不允许 provider 在后台继续
写入。

如果 adapter boundary 无法把一个 observation 精确归属到当前 Attempt，领域值应表达 partial／unavailable。它不能按
时间相近、数组位置或 ambient current owner 猜归属。
