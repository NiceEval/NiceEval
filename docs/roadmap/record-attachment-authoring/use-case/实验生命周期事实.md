# Experiment 生命周期生产 Run 事实

一个 Experiment Plugin 可以为整份 Run 生产领域事实。SDK 把 Run producer lifecycle 绑定到 Run-owned adapter：

```ts
export const workerService = definePlugin<WorkerServiceOptions>({
  name: "com.example.worker-service",
  behaviorRevision: "4",
  experiment({ monitor }) {
    return {
      recordAdapters: {
        run: [
          defineRunRecordAdapterBinding({
            adapter: workerServiceRecord,
            behaviorIdentity: monitor.behaviorIdentity,
            open: ({ run, signal }) => monitor.open({ run, signal }),
            seal: (session, { run, exit, signal }) =>
              monitor.seal(session, { run, exit, signal }),
            release: (session, { run, exit }) =>
              monitor.release(session, { run, exit }),
          }),
        ],
      },
    };
  },
});
```

Run owner open 时 reserve family 并登记 pending obligation。producer 在 Experiment setup 前 acquire，在 teardown 后
seal／release，再由 adapter 提交一次 sealed Run value。正常“没有启动 worker”必须是领域 explicit state，不能靠不写
Attachment 表示。

普通 Experiment 只挂载领域 Plugin：

```ts
export default defineExperiment({
  plugins: [workerService({ monitor: localWorkerMonitor() })],
});
```

同一个 Plugin 若还包含 Attempt facts，必须另放 `recordAdapters.attempt`。它们属于 pair／Attempt occurrence，不共享
Run session、grant 或 seal barrier。
