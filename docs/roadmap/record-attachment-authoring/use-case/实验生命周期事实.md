# Experiment 生命周期写入 Run 事实

Experiment 的 setup 与 teardown 都属于同一份 Run lifecycle。它们可以各写一个 Run-owned family；同一
owner/name 仍只允许一次 command。

`record-attachments/worker-service.ts` 定义两个独立事实。它们各自有稳定名称，因此 setup 与 teardown 不会竞争
同一个 reservation。

```ts
import { Schema } from "effect";
import { defineRecordAttachment } from "niceeval/record";

export const workerServiceStarted = defineRecordAttachment({
  owner: "run",
  name: "com.example.worker-service-started",
  versions: {
    v1: {
      schema: Schema.Struct({ endpoint: Schema.String }),
      blobRefs: () => [] as const,
    },
  },
  current: "v1",
  migrations: () => ({}),
});

export const workerServiceStopped = defineRecordAttachment({
  owner: "run",
  name: "com.example.worker-service-stopped",
  versions: {
    v1: {
      schema: Schema.Struct({ reason: Schema.Literal("completed") }),
      blobRefs: () => [] as const,
    },
  },
  current: "v1",
  migrations: () => ({}),
});
```

`experiments/worker-service.ts` 只为该 Experiment occurrence 授予两个 exact definition-object 的 write 权。

```ts
import { defineExperiment } from "niceeval";
import {
  workerServiceStarted,
  workerServiceStopped,
} from "../record-attachments/worker-service.js";

let workerService:
  | { readonly endpoint: string; readonly stop: () => Promise<void> }
  | undefined;

export default defineExperiment({
  agent: workerAgent(),
  recordAttachments: {
    write: [workerServiceStarted, workerServiceStopped],
  },
  async setup(ctx) {
    workerService = await startWorkerService({ signal: ctx.signal });
    await ctx.record(workerServiceStarted, {
      endpoint: workerService.endpoint,
    });
  },
  async teardown(ctx) {
    if (workerService) {
      await workerService.stop();
      await ctx.record(workerServiceStopped, { reason: "completed" });
    }
  },
});
```

`workerServiceStopped` 只在 `stop()` 成功后形成；teardown failure 不会留下“已经停止”的假事实。

这两个 `ctx.record()` 都写入 Run，而 Eval body 与 Eval Plugin 得到的是 Attempt context。setup、teardown、封口
和失败归属的完整顺序只在 [Lifecycle](../lifecycle.md) 定义。

读取端独立安装同一批 definitions：

```ts
import { defineConfig } from "niceeval";
import {
  workerServiceStarted,
  workerServiceStopped,
} from "./record-attachments/worker-service.js";

export default defineConfig({
  recordAttachments: {
    install: [workerServiceStarted, workerServiceStopped],
  },
});
```

install 不允许 setup 或 teardown 外的代码写入，write 也不让 config、CLI 或 reader 自动取得 migration trust。
