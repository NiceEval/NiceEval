# 内建事实复用同形 binding

Assertions、Verdict、Score、Diff、Timing 与 Plugin provenance 都先形成各自 sealed domain value，再由 package-private
official adapter binding 写入。

```ts
const assertionsBinding = defineAttemptRecordAdapterBinding({
  adapter: assertionsRecordAdapter,
  behaviorIdentity: assertionsBehaviorIdentity,
  open: openAssertionsCollector,
  seal: sealAssertions,
  release: releaseAssertionsCollector,
});
```

official adapter 只多一枚 package-private `niceeval.*` namespace token。它仍经过：

```text
total obligation
  → owner Scope
  → sealed value
  → current adaptation target
  → schema / plain-data / closure validators
  → tracked command / poison
  → generic sink / accepted event
```

公共包不导出 official adapter、binding、installation 或 writable definition。它只导出领域 Analysis API。官方不存在
parallel Effect facade、raw draft 或 schema bypass；否则无法证明与第三方机械中立。
