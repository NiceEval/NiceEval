# 检出到子目录

需要把 repository 放在 workdir 的子目录时使用 `into`：

```ts
sandboxLayer().prepare(
  checkout({
    repository: "https://github.com/acme/project.git",
    commit: "3f7c1f9a03e70cc13eaa9bdb7db891f26f74a836",
    into: "packages/upstream",
  }),
  defineSandboxCommand(async (sandbox) => {
    await sandbox.exec("pnpm install", { cwd: "packages/upstream" });
  }),
);
```

`into` 以 Sandbox workdir 为路径 resolution 起点。绝对路径、`..` 越界和符号链接逃逸在写入前拒绝。
consumer 只删除本次声明的目标目录；它不会把 workdir 中其它准备命令生成的文件当作 repository 内容。
