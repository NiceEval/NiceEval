# 并行运行共享宿主获取

两个 Invocation 或多个并行 Attempt 同时请求同一 commit 时，调用面仍是普通 `checkout`，无需用户加锁。

第一个请求 reservation 后执行 fetch 与 projection build；其余请求等待同一个发布结果。
发布成功后所有等待者各自取得 read lease 并向自己的 Sandbox 交付。
builder 失败时不会留下可命中的半成品；等待者收到同一具名准备失败，也不会偷偷各自访问 origin。

同一 repository 的不同 commit 可以并行生成投影，但 SourcePool fetch 由 pool write lease 串行化，避免两个 Git 进程破坏同一可增长状态。
