# File Diff 写入 Record

File Diff 与 Assertion evidence 的 durable 角色不同。它有独立的 typed reader、projection、schema 演进与历史
Attempt 读取价值，因此使用 Attempt-owned `niceeval.diff` Attachment。

## 一次冻结，两种消费

```ts
t.sandbox.fileChanged("src/index.ts", {
  status: "modified",
  after: includes("new implementation"),
});
```

runner 在作者 settle 后只导出一次 frozen workspace diff 语义值。diff Assertion evaluator 用它判定；Evaluation
adapter 也把同一个值编码为 durable payload。

```ts
const diffOccurrence = {
  recordAttachments: { write: [workspaceDiffDefinition] },
};

const writeDiff = (ctx, frozenDiff) =>
  ctx.recordEffect(
    workspaceDiffDefinition,
    workspaceDiffAdapter.toPayload(frozenDiff),
  );
```

definition、grant 与 adapter 是 package-private；命令仍经过与第三方事实相同的 reservation、snapshot、closure、
poison、sink 与 publication。generic writer 不知道 changed path、hunk 或 send-window attribution。

Assertions 可以保存下列语义材料，指出判定依赖同一 Attempt 的 Diff：

```ts
{
  kind: "record-attachment",
  schemaId: "niceeval.diff/v1",
  preview: "src/index.ts modified",
}
```

它不是跨 Attachment capability。它没有 blob ref、path loader 或“读取最新 Diff”的动作；whole-Attempt contract 在
发布前核对实际 Diff write 与 Assertion claim 是否一致。

## 中立读取

```ts
const diffByAttempt = attemptSlotProjection(agentWorkspaceDiffProjector);

const projected = yield* projectAnalysisSample({
  sampleHandle,
  projection: diffByAttempt,
});
```

script 与 Report 使用同一个 exported projector，没有官方 Report 私有 reader。Report 的静态 manifest 只是保存
`diffByAttempt` declaration，再调用同一个 projection kernel。

## Migration 与 reuse

`niceeval.diff` 自己声明逐相邻 migration。普通 reader 遇到旧 schema 只返回 `migration-required`；
`RecordMaintenanceAccess.migrate` 才执行 converter。v1 不预先建立 Evaluation migration group。

若 future Diff schema 还要求同步改写 Assertions 中的 schema 指示，则采用该版本前必须定义完整 migration group。
缺少 group authority、成员映射、原子提交与失败契约时，该迁移明确为 migration-unavailable。

历史 Attempt 被采用时，它的 Diff 随 exact Attempt 原样可读。是否要求 Diff available/current 才允许采用，由
`ExecutionReusePlan` 的具名领域 policy 决定；RecordAttachment definition 与 verified-read cache 都不决定复用。

## 边界反例

| 尝试 | 结果 |
|---|---|
| generic writer 根据 payload 名字推断这是 Diff | 不允许；领域 adapter 先编码，writer 不认识 Diff |
| reader 自动把 `v1` 改写为 future `v2` | 不允许；返回 migration state，等待显式 maintenance |
| verified-read cache hit 直接判定 Attempt 可复用 | 不允许；cache identity 不是 behavior / eligibility identity |
| Diff 缺失时伪造成空变化 | 不允许；unavailable 与 available empty 是两个状态 |
