# File Diff

File Diff 是 NiceEval 官方固定事实，不退化成用户 Artifact 或任意 JSON。普通作者只通过 Sandbox 与 Assertion API 使用它。

## Capture

```ts
await t.check("只修改允许的文件", async (assert) => {
  const diff = await t.sandbox.diff();

  assert.fileChanged(diff, "src/index.ts");
  assert.fileUnchanged(diff, "package-lock.json");
});
```

Sandbox 在 Attempt Scope 内形成 sealed diff。官方 Capture 保存 file identities、change kind、hunks、binary refs、limits 与 exact
Assertion Evidence refs。普通作者不选择 durable payload shape 或 blob path。

## Analysis

官方 `niceeval/analysis/diff` 发布：

```ts
import {
  addedLineCount,
  changedFileCount,
  changedPath,
  diffState,
} from "niceeval/analysis/diff";
```

这些 fields 以 logical slots 为 population。diff unavailable、binary-only、truncated 与 no-change 不会合并：

| Capture fact | `changedFileCount` | issue |
|---|---:|---|
| available empty diff | 0 | none |
| available text diff | 文件数 | limits 进入 refs / issue |
| binary-only | 文件数 | binary content 不伪装成 0 lines |
| unavailable | null | unavailable |
| failed | null | producer failed |

`changedPath` 是有界 Dimension，只能从 sealed diff manifest 形成。Report 不能临时扫描 Sandbox 或宿主文件系统。

## Report

```tsx
export const DiffOverview = defineComponent(async (_props, { sample }) => {
  const rows = await aggregate(sample, {
    by: { agent },
    values: { passRate, changedFileCount, addedLineCount },
  });

  return (
    <Table
      rows={rows}
      columns={["agent", "passRate", "changedFileCount", "addedLineCount"]}
      evidence={{ target: attemptDiffPage }}
    />
  );
});
```

Attempt Diff PageFamily 的 key 来自 stable Attempt identity Dimension。Table 只在 exact instance 存在时生成链接；一个聚合格含多条
refs 时，页面先展示 Evidence 列表，不任选一个 Attempt。

## 为什么不是 Metric

`changedFileCount` 是从官方 File Diff 派生的 Measure，但 File Diff 本身不是 Metric：

- hunks 与 path identity 需要结构关系；
- Assertion 要引用 exact diff material；
- binary、truncated 与 unavailable 有领域状态；
- 详情页需要完整 diff closure。

第三方若只需要保存一个文件数，可以定义 Metric；若需要 File Diff 的完整语义，应使用官方 Sandbox / Diff API，而不是创建平行
schema。
