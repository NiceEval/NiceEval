# 断言与证据写入 Record

Evidence 不是第四层，也不是通用 Attachment。它是某条 Assertion 作出判定时使用的材料，由 Assertions 领域决定
snapshot、blob、coverage 与 limitations。

## 作者只声明 Assertion

```ts
const result = await t.sandbox.runCommand("bash", ["tests/run-tests.sh"]);

t.check(result, commandSucceeded())
  .label("测试通过");
```

调用发生时，Assertions producer 冻结 subject 与 evaluator 实际使用的 evidence。安全且有界的值保存为 snapshot；
较大材料保存为 `niceeval.assertions` 自己 closure 中的 blob。secret 不进入任一形态。

## 内建 adapter 进入同一 command kernel

下面是 package-private 的目标接线形状，不是公共 official definition：

```ts
const assertionsOccurrence = {
  recordAttachments: { write: [assertionsDefinition] },
};

const writeAssertions = (ctx, sealedAssertions) =>
  ctx.recordEffect(
    assertionsDefinition,
    (blobs) => assertionsAdapter.toPayload(sealedAssertions, blobs),
  );
```

`assertionsAdapter` 负责 entry order、criterion、subject、evidence、coverage、limitations 与 sealed result 的联合
不变量。generic writer 只验证 exact grant、Attempt owner、schema、plain-data snapshot 与 own blob closure。

Evidence 没有自己的 definition、grant 或 migration。Assertions schema 演进时，Evidence material 随
`niceeval.assertions` 的相邻 migration 一起演进。

## 从同一 snapshot 读取

```ts
const assertionsByAttempt = attemptSlotProjection(assertionsProjector);

const projected = yield* projectAnalysisSample({
  sampleHandle,
  projection: assertionsByAttempt,
});
```

`ProjectedSample` 保留 excluded、not-recorded、core-invalid 与每个 Attachment read state。available entry 中的
evidence 已经是 self-contained snapshot / materialized own blob；Report 不回到 Sandbox 或当前 worktree 重新采集。

Report 可以把同一个 declaration 放进自己的 manifest：

```ts
const inputs = reportInputs({ assertions: assertionsByAttempt });
```

Report host 在 callback 前形成 projected value 与 problems。页面只选择怎样呈现 entry、coverage 与 evidence；
不能隐藏 migration、invalid 或 unavailable。

## 边界反例

| 尝试 | 结果 |
|---|---|
| 把 Evidence 写成通用 `niceeval.evidence` | 没有该公共模型；Evidence 留在拥有判定语义的 Assertions family |
| 在 Assertions payload 保存 File Diff 的 blob ref 或 path | builder 不授予 ref；dynamic input 在 closure validation 被拒绝 |
| Report 重新运行 command 取得“最新证据” | 不允许；Report 只消费 Record 中的 call-time material |
| 把 unavailable evidence 改成空数组 | 不允许；entry coverage 与 limitations 必须保留 |
