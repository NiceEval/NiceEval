# 实验环境较重

## 项目形态

所有 Eval 使用同一种基础环境,重的是随 Experiment 变化的工具。
例如记忆对照实验要安装 mempal 二进制、模型 cache 与配套文件,普通对照实验不需要这些内容。

题目没有自己的 `environment`;Experiment 选择基础 Sandbox,再通过 Layer 声明实验工具。

```typescript
// experiments/compare/codex--mempal.ts
export default defineExperiment({
  agent: codexAgent({ mcpServers: [mempalMcp] }),
  model: "gpt-5.6-luna",
  sandbox: e2bSandbox({ template: BASE_TEMPLATE }),
  layers: [mempal],
  flags: { memory: "mempal" },
});
```

`mcpServers` 决定 Agent 怎样连接 mempal,Layer 负责 mempal 在 Sandbox 中真实就位。
`flags` 只提供报告分组坐标;环境身份由 Layer identity 与 sandbox case 身份承担。

## 定义实验工具

```typescript
// experiments/shared/mempal.ts
import { defineLayer } from "niceeval/sandbox";

const identity = {
  version: "0.9.0",
  recipeRevision: 3,
  installerDigest: MEMPAL_INSTALL_SH_SHA256,
  model: "minilm-l6@sha256:9f2c...",
};

export const mempal = defineLayer({
  name: "mempal",
  identity,
  requires: { network: "direct" },
  check: async (sandbox) => {
    const actual = await readMempalInstallation(sandbox);
    if (!actual) return { ok: false, reason: "missing" };
    if (!sameIdentity(actual, identity)) {
      return { ok: false, reason: "identity-mismatch", detail: actual.summary };
    }
    return { ok: true, actual: { version: actual.version, model: actual.model } };
  },
  apply: async (sandbox, ctx) => {
    ctx.progress({ message: "installing mempal", current: 1, total: 2 });
    await installMempal(sandbox, MEMPAL_INSTALL_SH);
    ctx.progress({ message: "warming embedding model", current: 2, total: 2 });
    await warmMempalModel(sandbox, identity.model);
    await writeMempalInstallation(sandbox, identity);
  },
});
```

`check` 核对整个目标身份,而不只检查命令是否存在。
版本、安装配方或模型任一项变化时,旧安装都会 miss 并由 `apply` 补齐。

## 为什么可能需要 `sandboxReuse`

默认情况下,每条 Attempt 使用全新 Sandbox。
基础 template 没有预装 mempal 时,每个新 Sandbox 的首次 check 都会 miss,所以 Layer 提供了正确身份与统一协议,却不会自动消除重复安装成本。

安装成本很高、Experiment 又允许 workdir 外状态残留时,可以显式复用 Sandbox:

```typescript
export default defineExperiment({
  agent: codexAgent({ mcpServers: [mempalMcp] }),
  sandbox: e2bSandbox({
    template: BASE_TEMPLATE,
    lifetimeMs: 60 * 60_000,
  }),
  layers: [mempal],
  sandboxReuse: true,
  maxConcurrency: 1,
});
```

复用窗口中的第一条 Attempt 安装 mempal,后续 Attempt 每次仍执行 check,但通常直接命中。
`maxConcurrency: 1` 让 Runner 一次只需要一个 Sandbox;Sandbox 到期、reset 失败或被替换时,新窗口仍会重新安装。

`sandboxReuse` 改变跨 Attempt 的状态边界,不是无条件的性能开关。
不能接受 `$HOME`、`/tmp`、全局安装或后台进程残留时,保持默认隔离,再按[把环境层预装进产物](把环境层预装进产物.md)消除安装时间。

## 对照组

对照组使用另一份 Experiment,不声明 `mempal` Layer,也不注册对应 MCP server。
Layer identity 进入环境身份,所以工具版本与配方变化会使旧结果失效;命中、实测身份和逐层耗时都会进入记录。
