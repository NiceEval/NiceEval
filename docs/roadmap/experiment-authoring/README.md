# Experiment Authoring

本方向补齐具名 Experiment 族的稳定作者身份。每个成员仍拥有独立的发现、选择、Run 与历史关联边界。

## 子方向

- [具名 Experiment 族](families/README.md) —— 用 keyed record 从一个入口展开多个稳定 Experiment ID。

Experiment 的人类展示值已经由当前 [Experiment 展示名称](../../feature/experiments/display-names/README.md)契约拥有。
具名族只定义成员怎样形成稳定 ID，不复制展示语义。
