# 上层变化不改持久格式

Assert-first API、执行算法和 Report 可以独立演进。判断依据是已发布事实是否改变，不是函数名或内部求值顺序是否改变。

## 稳定边界

```text
Assert-first author API
        ↓
Assertion evaluator / matcher / Plugin lifecycle
        ↓
producer-owned RecordAttachments
        ├─ niceeval.assertions/v1
        ├─ niceeval.verdict/v1
        ├─ niceeval.score/v1
        ├─ niceeval.eligibility/v1
        └─ niceeval.evaluations/v1
        ↓
generic Record
```

Record 保存规范化 AssertionResult，不保存 matcher、作者调用顺序、memoization 或 evaluator runtime object。

`EvaluationRecordContract` 先验证 Evaluation producer 的领域组合，再调用 generic writer。generic writer 不知道 Verdict、Score 或 Evaluation 的业务规则。

## 每层拥有自己的变化

| 变化 | owner | 动作 |
|---|---|---|
| Assertion authoring、matcher、Plugin lifecycle | producer/behavior | 必要时更新 input、config 或 reuse identity |
| AssertionResult payload | Assertions RecordAttachment | 新相邻 schema 与 migration policy |
| consumer typed view | Projection | 新 projector/API |
| 页面、聚合与下载 | Report | 新 Calculation/Page/Download |
| owner、引用、完成判断或 Core shape | Record | 新 Core major 与相邻 converter |

一次 fixture 产生相同 bytes 不能证明行为等价。reuse 条件可能变化时，behavior identity 仍要更新。

## Pass 与 Score

Run-owned Evaluation RecordAttachment 保存 Slot 与 Eval 的定义期关系及 `pass | score`。离线 Report 不回读当前源码猜 Evaluation 类型。

Pass 和 Score 的 origin Attempt 都保存完整四态 Verdict。Score Eval 另有 Score RecordAttachment；Verdict 与 Score 不互斥，也不可互推。

这些字段不进入 Core。未来新增 ranking、pairwise 或其它 Evaluation 类型时，先演进 Evaluation RecordAttachment，而不是扩张 RunDocument 联合。

## reuse 是独立边界

能读取一个 Attempt 不表示当前目标可以沿用它。reuse planning 声明自己需要的 Verdict、Score、Eligibility 与 behavior domain。

缺失、migration-required、migration-unavailable、unsupported、invalid 或 domain mismatch 都形成 gap。

Record 只保存当时的 claim，不持续认证某个 Attempt “现在仍可复用”。

## 何时需要 migrate

RecordAttachment payload、blob ref 或 closure 改变时发布相邻 schema。请求 current family 的功能遇到完整 converter 链时返回 `migration-required`；遇到 `not-losslessly-migratable` 时返回 `migration-unavailable`。后者保留 bytes，不提示重跑 migrate。其它 RecordAttachment 与 Core 继续可读。

unknown RecordAttachment 始终是 unsupported，不因为 current family 缺少能力而改称 migration-unavailable。

Core owner、引用、目录、完成判断或 shape 改变时发布 Record major。普通 reader 整体要求 migration。

converter 接收完整、自包含且已经 materialize 的 Attachment value；source payload 是
package-owned deep-frozen JSON snapshot，old bytes 只经同步 `bytes(ref)` 读取。target
builder 新建 refs，并以写侧 Stream 提供 target blobs。它不运行 Assertion evaluator、
projector、reuse planning 或 Report。无法从旧事实得到的新值不允许由当前源码补写。

## 验收问题

每次上层重构只检查：

1. 已发布 payload 的 shape 或语义是否改变？
2. typed view 是否改变？
3. 相同输入的可观察行为或 reuse 安全条件是否改变？
4. Core owner、引用、完成判断或 shape 是否改变？

四项分别归 RecordAttachment schema、projector/API、behavior identity 与 Record major；互不替代。
