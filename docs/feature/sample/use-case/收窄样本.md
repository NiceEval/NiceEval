# 收窄一份 AnalysisSample

## 解决的问题

一份 `AnalysisSample` 已经包含完整比较范围，但某张报告只需要 `security/` Eval。收窄应保留原分母状态，不能让 renderer 临时决定哪些成员消失。

## 使用方式

```ts
import { Effect, Either } from "effect";

declare const sample: AnalysisSample;
declare const securitySlotIds: readonly SlotId[];

const program = Effect.gen(function* () {
  const narrowed = narrowAnalysisSample(sample, {
    slotIds: securitySlotIds,
  });

  if (Either.isLeft(narrowed)) {
    return yield* Effect.fail(narrowed.left);
  }

  return narrowed.right;
});
```

`narrowAnalysisSample()` 只读取传入的 `AnalysisSample`：

1. 匹配项保持 `included`、`not-recorded` 或 `core-invalid`。
2. 未匹配项变成 `excluded`。
3. excluded 项在 `base` 中保留收窄前的状态，不递归包另一个 excluded。
4. 输出继续在完整 `slots` 中保留四种状态。

因此 Reports 可以同时说明“范围外”“没有 Member”和“Record 数据损坏”，不会把三者折成同一个空值。

## 边界

- 收窄不重新打开 Record，也不读取修改后的 Attempt。
- selector 只做精确字符串匹配，不接受任意回调。
- 收窄是单调交集；不同 selector 不能把已经 excluded 的 slot 重新纳入，相同 selector 再应用是 identity。
- 要看到 Record 的后续编辑，重新运行同一个 analysis selection。
- 跨 Record 分析由调用方分别形成 `AnalysisSample`，再在业务分析层明确组合；Sample Library 不提供隐含合并。
