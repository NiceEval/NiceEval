# 收窄一份可复核的样本

## 解决什么问题

你已经有一份完整的比较 Sample，但只想把 `security/` Eval 交给一张报告或一个同事。
收窄不能让分母、provenance 或缺口在展示时才临时决定。

## 全流程

```ts
const security = narrowSample(sample, {
  evals: ["security/"],
  experiments: ["compare/"],
});
```

1. `narrowSample()` 只检查输入 Sample denominator 已定的 slot；runs、evals 与 experiments 都做 exact
   string match，字段内 OR、字段间 AND。
2. 它以 JCS 规范化 selector，并把原 Sample identity 和 selector 写入新 identity。
3. 匹配项保持原 included/excluded/unavailable state；未匹配项进入 `excluded`。原 `sources`、分母、
   provenance、可用 membership 与 proof 都随新样本保留，范围内但 unavailable 的项不会被误升为 included。
4. 报告的 plan 接收 `security`，只枚举它已经确定的成员。

因此，收到 `security` 的人不需要访问源 Store，仍能看见它来自哪些 source Graph、哪条 membership，也能区分「被范围排除」与「范围内但不可用」。

## 边界

- 收窄不会重新打开 Record、读取新的 source Graph 或重选 contribution。
- selector 不是任意回调；未知字段被拒绝，默认值参与规范化 identity。
- 要把多份 Sample 放到一起，使用 `unionSamples()`，不要先剥成 Attempt 数组再自行去重。
