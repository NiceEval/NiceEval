# 收窄一份 Sample

## 解决的问题

一份 Sample 已经包含完整比较范围，但某张报告只需要 `security/` Eval。收窄应保留原分母状态，不能让 renderer 临时决定哪些成员消失。

## 使用方式

```ts
const security = narrowSample(sample, {
  evalIds: ["security/auth", "security/input"],
});
```

`narrowSample()` 只读取传入的 Sample：

1. 匹配项保持 `included`、`not-recorded` 或 `invalid`。
2. 未匹配项变成 `excluded`。
3. excluded 项在 `previous` 中保留原状态，并保存本次 selector。
4. 输出的四个状态子序列继续与完整 `slots` 对应。

因此 Reports 可以同时说明“范围外”“没有 Member”和“Record 数据损坏”，不会把三者折成同一个空值。

## 边界

- 收窄不重新打开 Record，也不读取修改后的 Attempt。
- selector 只做精确字符串匹配，不接受任意回调。
- 要看到 Record 的后续编辑，重新调用 `selectSample()`。
- 跨 Record 分析由调用方分别选择 Sample，再在业务分析层明确组合；Sample Library 不提供隐含合并。
