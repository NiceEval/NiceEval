# 源码树的装配与投影

完整源码证据先经过归属和建树，成为面无关的 `AnnotatedEvalSource`；终端与 web 再各自投影要显示的行和默认展开态。
两个阶段都不改变断言、给分记录或 send 的原始顺序。

## 归属

每条带 `loc` 的痕迹取完整路径。
挂点按下面的顺序确定：

1. 路径中存在主干项目帧时，取最内层的主干帧为挂点，其后的帧成为调用子树。
2. 路径不经过主干时，按最外层项目帧进入 `detached`。
3. `callers` 为空且声明位置在主干时，直接挂到主干声明行。
4. `callers` 为空且声明位置在其它已捕获文件时，按该文件进入 `detached`。
5. 没有 `loc` 的断言与给分记录进入 `unmapped`。

越界行和缺失正文不能被当作没有 `loc`。
它们保留原路径，成为对应节点上的 `unavailable` 缺口。
没有位置的 send 不进入 `unmapped` 区。

## 建树

挂点之后的每个路径段形成一条边：项目段建 `source` 节点，第三方包段建 `package` 节点，正文读取失败的项目段建 `unavailable` 节点。
更深的可用节点继续挂在 package 或 unavailable 段下面，不因中间缺一份正文而丢失。

相同调用行、相同路径段的边合并。
最深项目帧的声明行承载标注；汇总从叶子向根累加。
前置中止沿经过的调用边向主干传播，并把中止位置之后实际未到达的源码行标成降灰候选。

## 投影

`projectSourceView()` 是唯一裁行与展开入口：

```ts
projectSourceView(
  source: AnnotatedEvalSource,
  options: {
    mode: "default" | "full" | "file" | "web";
    file?: string;
    budgetLines?: number;
  },
): SourceContent
```

`AnnotatedSourceResult` 保留与完整树相同的节点关系，但节点的 `lines` 只含本次要展示的行，并为每条调用边声明默认展开态。
省略区段不进入数组，渲染面按行号不连续显示 `... N lines`。

### 行选择

每个节点先选择有标注、有调用或有中止标记的必留行，再向两侧扩张上下文：

| 节点 | 上下文半径 | 折叠条件 |
|---|---:|---|
| 主干 | 3 行 | 连续 8 行以上没有标注、调用或中止 |
| 调用片段与 detached | 2 行 | 连续 4 行以上没有标注、调用或中止 |

主干的起始范围是整个入口文件。
默认与 web 模式可以折叠无关区段；单文件模式显示指定文件全文。
 `full` 表示内联全部调用路径，不表示禁用节点内部的无关行折叠。

### 展开与预算

默认终端模式只展开满足任一条件的调用路径：

- 有未通过或 unavailable 断言；
- 计分制下有丢分；
- 有前置中止。

默认预算是 400 个投影源码行。
超过预算时，先收起更深的路径；同深度先收只有 soft 失败的路径，再收 gate 失败路径。
主干投影行与调用汇总行不丢弃；收起路径里的标注仍留在完整证据树中。
当前投影只显示汇总，并提示 `--source=full`。

web 模式保留全部路径，用原生 `<details>` 表达展开。
含未通过、unavailable、丢分或中止的路径默认 `open`，其它路径默认收起。
单文件模式不应用调用树预算。

## 路径不完整时的结果

| 输入 | 结果 |
|---|---|
| 只有主干声明位置 | 正常挂主干行 |
| 只有其它文件的声明位置 | 进入该文件的 detached 片段 |
| 中间项目文件没有正文 | 保留 unavailable 段，更深节点继续挂在其下 |
| 经过第三方包 | 保留不可展开的 package 段，更深节点继续挂在其下 |
| 没有声明位置 | 断言与给分记录进入 unmapped |
| 没有任何源码 | `evalSource` 为 `null`，源码切片报告 unavailable |

归属与建树只依赖已有事实，不根据函数名、断言数量或文件名猜调用关系。

## 两个渲染面

- text 面只负责缩进层级、汇总行、省略行和终端宽度截断。
- web 面只负责 `<details>`、汇总 pill、行状态和源码横向滚动。

两个面都消费 `AnnotatedSourceResult`，不重新分桶、汇总或选择上下文行。
web 视觉细节见 [`toAttemptSource(attempt)`](../components/primitives/source-view.md)。
