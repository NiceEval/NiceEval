# 把报告嵌入自己的产品页

在能打开记录根的服务端或构建进程中选择 Sample，并调用普通转换：

```ts
const points = await aggregate(sample, {
  by: { agent },
  values: { passRate, costUSD },
});
```

把可序列化 points 交给 `niceeval/report/react`：

```tsx
<Scatter
  points={points}
  x="costUSD"
  y="passRate"
  point="agent"
/>
```

React 入口不读取 Record、Sample 或 artifact，也不运行 page runtime。
运行时看不见记录根时，在构建期把 Result 写成 JSON；记录根有新 Run 后重新构建。

证据下钻的路由同样需要对应 artifact。
用 `publish()` 把所需结果物化到产品可读目录。
