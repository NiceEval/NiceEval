# 编写项目主题

主题文件只声明设计令牌和必要样式，不复制报告组件：

```ts
import { defineTheme } from "niceeval/report";

export default defineTheme({
  appearance: "system",
  accent: { light: "#6D5DFC", dark: "#A99EFF" },
  positive: { light: "#047857", dark: "#6EE7B7" },
  negative: { light: "#BE123C", dark: "#FDA4AF" },
  warning: { light: "#A16207", dark: "#FDE047" },
  radius: "4px",
});
```

组件应读取主题令牌和已计划的 `dimensionPins`，不能硬编码另一套品牌色。
自定义组件的取色规则见 [使用主题色](../../构建报告/自定义组件/使用主题色.md)。
