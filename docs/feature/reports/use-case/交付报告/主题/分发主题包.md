# 跨项目分发主题包

多个项目共享主题时，把 `defineTheme` 的返回值作为包的默认导出。消费方在报告定义或
`niceeval.config.ts` 中 import 这个 branded `ThemeDefinition`，再赋给 `theme` 字段，不复制令牌。

需要允许消费方派生配色时，包另行具名导出 plain `ReportTheme` 输入。消费方展开这份输入并再次
调用 `defineTheme()`；不能展开 opaque ThemeDefinition。一次性 CLI 试装仍指向默认导出主题的本地
文件入口。

主题包只包含呈现定义，不依赖某个 Record Graph。需要连报告结构一起交付时，另行导出
`defineReport` 的返回值；静态发布流程见[导出静态站](../导出静态站.md)。
