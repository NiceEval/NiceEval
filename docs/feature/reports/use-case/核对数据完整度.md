# 核对数据完整度

团队要知道报告是否基于完整的通过率输入，而不是把有值的 Attempt 当成全部 Attempt。

## 选择固定范围

```sh
niceeval show --run <run-id> --report ./reports/quality-coverage.ts --page /
```

--run 固定一个 Run 的 Sample。Analysis 在读取可用值前固定该度量的 expected member，因此 total 不会因数据缺口而改变。

## 显示完整度

```tsx
import {
  aggregate,
  defineReport,
  formatMetricValue,
  Grid,
  passRate,
  Stat,
  Table,
} from "niceeval/report";

export default defineReport({
  title: "Pass-rate coverage",
  pages: [
    {
      id: "coverage",
      path: "/",
      title: "Coverage",
      presentation: "page",
      render: async sample => {
        const [summary] = await aggregate(sample, {
          by: {},
          values: { passRate },
        });

        return (
          <Grid>
            <Stat label="Pass rate" value={formatMetricValue(summary.passRate)} />
            <Table rows={[summary]} />
          </Grid>
        );
      },
    },
  ],
});
```

by: {} 对同一个固定总体产生恰好一行。假设 100 个成员应参与通过率口径，只有 20 个成员贡献结果，其中 16 个通过：

```text
value:   0.80
samples: 20
total:   100
state:   partial
```

页面写 80% · 20 / 100 · partial。Table 保留同一个完整 MetricValue，Stat 只使用它的格式化显示，因此不会把 20 / 100 改写成 20 / 20。

## 分清状态

| state | 页面必须说明什么 |
|---|---|
| available | 全部分母成员都贡献了值。 |
| partial | 已贡献数、既定分母和每个缺口 issue。 |
| empty | 输入完整但领域结果合法为空，不等于缺失。 |
| unsupported | 当前 host 不能提供所需输入。 |
| failed | 输入读取或归并失败，以及可复核 refs。 |

状态不依赖组件。view 与静态目录在完整站点构建中关闭使用 passRate 的 Page；`show` 只关闭选中 Page。各呈现面都显示
同一 Analysis 口径的 samples、total、issues 和 refs。

## File Changes 的三种空态

文件变化的完整度不应借用 MetricValue 的 `empty`。Attempt 页面应直接显示 File Changes 的 collection 和 trajectory：

| 状态 | 页面必须说明什么 |
|---|---|
| complete 且零变化 | 完整轨迹证明没有 agent 归因的路径变化。 |
| partial 且安全前缀为空 | 未捕获任何前缀不等于没有变化；显示 limitation。 |
| `not-recorded` | collector 不适用于该 Attempt，不是空轨迹。 |

partial 的 limitation 与 `net: indeterminate` issue 属于不可隐藏的数据问题。页面可把 reliable `net` 放进摘要或
`DiffView`（差异视图），但默认仍按 send 区间显示 trajectory。

## 局部影响

问题只影响使用该度量的单元。其它质量页可以读取另一项已发布度量，并在通过率数据 unavailable 时继续呈现。反过来，Report 不能通过隐藏 coverage Page、过滤 rows 或把 null 设为零来消除问题面。

如果 show 目标 Page 的 load、render 或组件失败，命令返回单目标执行错误。全站路径中任一 Page 失败时，Host 不能形成
ClosedSiteRevision，view 保留 last-good。它与 MetricValue 的 partial、unsupported 或 failed 不同：后者是可见数据状态。
