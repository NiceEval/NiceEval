# 扫描参数档位的趋势与拐点

## 解决什么问题

你对 token budget、context 大小或另一个数值条件做了多档扫描,要找收益递减、回归或性价比拐点。

## 全流程

1. 数值条件在 Experiment 的 flag 或 label 中显式声明,不从 id 字符串猜。
2. 用 `numericFlag` 或 `numericLabel` 声明数值轴身份；在 plan 中用 `aggregate()` 声明带主读数的 EvidenceRow，再交给 `<Line points={...} x=... y=...>`。
3. 需要按 agent 或 lineage 分色时用 `color` 键绑定行字段，不另开 Dataset 查询对象。
4. y 轴先放主成功读数;成本、耗时需要独立图或与前沿图互证。
5. 点缺失时查 `coverage` 的 total、included、excluded、unavailable 及其 causes，不连出虚构线段。

## 边界

- 只有基准/候选两点且关心精确差值时，在 plan 中声明成对比较 Calculation。
- x 轴不是数值进程时,改用散点、表或柱状图。
