# 固定题集做考试成绩单

## 解决什么问题

你有一份稳定题集,每道题属于明确分科,缺考也应进分母;目标是成绩单,不是探索性平均值。

## 全流程

1. 在报告旁声明 `scoreboard` Calculation，并用固定 Sample 与 rubric 明列考试边界，不用碰巧存在的题猜分母。
2. 按路径组或业务分类设权重,选定通过制的 `passRate` 或计分制主读数。
3. 每行用 agent、experiment 或自定义维度,展示总分和分科得分。
4. 对缺失题目同时展示 Sample coverage 证据,避免把没跑误认成完成。

完整代码见[考试示例](../../library/examples.md#报告旁复杂算法)。

## 边界

- 探索不固定的 Eval 集合时用 `aggregate()`，不要借通用成绩单 Calculation 制造伪考试。
- 一题内的部分完成先由 Record 事实建模；Reports 只展示 Projector 已交付的分数。
