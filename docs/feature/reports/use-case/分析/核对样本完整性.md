# 先证明数据范围值得相信

## 解决什么问题

一张图可以有正确公式，却因分母、membership、unavailable 或 verification 没有说清而被误读。

## 全流程

1. 页面先显示固定 Sample identity、完整 source Graph 集合与 canonical selection。
2. 显示 coverage 的 total、included、excluded、unavailable 及每类成员。
3. 显示每个主 MetricValue 的 basedOn 和 refs；available 显示 verification 与全部 issues，unavailable 显示全部 causes。
4. 在 Experiment table 中显示 membership provenance 与不可用原因。
5. 只有这些事实可见时，再显示排名、趋势或建议动作。

## 边界

- Sample notices、MetricValue coverage、Attempt details 和导出错误的归属不同，不能互相替换。
- 源 Record 中已有的证据导出失败是 export failure，不应在 Sample notice 中伪装成普通 unavailable。
- 历史分析始终交付另一份固定 Sample 或 union，而不是脱离 provenance 的 Run 数组。
