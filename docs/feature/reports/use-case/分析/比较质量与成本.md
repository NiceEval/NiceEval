# 比较质量、成本与前沿

## 解决什么问题

多个 Agent、模型或 flags 都跑了同批 Eval,你要找到质量和成本的取舍,而不是只按一个分数排名。

## 全流程

1. 先用标准报告 plan 中的质量—成本 Calculation 画前沿散点，并配 Experiment 行查看明细。
2. 需要替换坐标时用 `Chart` 的 scatter mark；`points` 选 executor 已交付的 Experiment 行，`by` 选 agent 或 label。
3. 需要同时审查三个以上读数时改用 `aggregate()`，让 coverage 与 evidence refs 留在每个格子。
4. 从异常点的 locator 下钻 Attempt,确认差异来自任务表现还是执行错误。

## 边界

- 要回答「A 精确比 B 差多少」时用成对比较 Calculation，不用散点图目测。
- 固定题集的总分和分科分属于报告旁成绩单 Calculation，不是前沿比较。
