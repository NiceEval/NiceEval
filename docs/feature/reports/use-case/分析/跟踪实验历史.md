# 跟踪一个 Experiment 的历次 Run

## 解决什么问题

你要比较同一个 Experiment 的多个历史 revision，而不是让一个当前范围随源 Store 漂移。

## 全流程

1. 为每个要比较的 Run revision 生成一份固定 Sample。
2. 需要同图比较时，用 `unionSamples()` 显式合并这些 materialized Sample，并选择 conflict policy。
3. 在 ReportPlan 中声明 Run provenance、MeasureCell 和趋势 Calculation。
4. renderer 只用已经生成的历史 points 绘制 line 或 table。

每个点都保留完整 source Graph 集合、adopted revision、membership proof、coverage 和 EvidenceValue。
没有统一比较键的历史 revision 不应被自动合并。

## 边界

- 历史是明确的 Sample 集合，不是 renderer 中扫描 Record 的便利函数。
- `show --history` 可以选择单个 Attempt 的预设 target；跨 Run 趋势仍需在 plan 中列出全部输入。
