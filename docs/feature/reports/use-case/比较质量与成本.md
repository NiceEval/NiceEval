# 比较质量与成本

团队要比较两个或多个完成 Run 的质量与成本，并看清每个读数的分母和缺口。

## 选择范围

先显式选择要比较的 Run。

    niceeval show \
      --run 01H7A0A0A0A0A0A0A0A0A0A0A0 \
      --run 01H7B0B0B0B0B0B0B0B0B0B0B0 \
      --report ./reports/quality-cost.ts

Sample 以每个 Run 的 expected slots 形成分母。没有 Member 的 slot 保持 <code>not-recorded</code>；核心引用有误的 slot 保持 <code>invalid</code>。比较页不能因为某个 Attempt 没有数值而把它从分母移走。

## 声明读数

该 Report 的质量 Calculation 声明 <code>niceeval.verdict</code>，成本 Calculation 声明 <code>niceeval.usage</code>。两项各自声明 policy：

    const quality = defineCalculation({
      id: "quality",
      inputs: [verdict],
      completeness: "requireComplete",
      evaluate(input) {
        return qualityFrom(input);
      },
    });

    const cost = defineCalculation({
      id: "cost",
      inputs: [usage],
      completeness: "allowPartial",
      evaluate(input) {
        return costFrom(input);
      },
    });

<code>qualityFrom</code> 与 <code>costFrom</code> 只读 CalculationInput。它们不按路径、时间或 locator 打开其它 Attempt。

## 读页面

质量 Calculation 在所有 required verdict 完整时显示通过率与完整分母。成本 Calculation 可以显示 partial，例如 <code>$3.20 · 20 / 100 · partial</code>。页面同时给出未参与成本公式的 80 个 slot 及原因。

如果 <code>niceeval.usage</code> unsupported，成本卡片写明 reader 不支持该通道。质量卡片仍可使用 verdict 计算。若 <code>niceeval.verdict</code> 被请求且 invalid，质量卡片显示具名 issue；不读取 verdict 的页面与另一个 Report 保持可用。

## 交付

同一 Report 可由终端或网页呈现。

    niceeval view \
      --run 01H7A0A0A0A0A0A0A0A0A0A0A0 \
      --run 01H7B0B0B0B0B0B0B0B0B0B0B0 \
      --report ./reports/quality-cost.ts

散点图必须给出同一批行的文字表。每一行展示 Run、质量、成本、observed、denominator 和状态，不能只靠点的位置或颜色传达 partial。
