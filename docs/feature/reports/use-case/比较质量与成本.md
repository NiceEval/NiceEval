# 比较质量与成本

团队要比较两个或多个完成 Run 的质量、时长和成本，同时看清每个读数的分母、缺口和 Evidence。

## 选择范围

先精确选择要比较的 Run：

```sh
niceeval show \
  --run 01H7A0A0A0A0A0A0A0A0A0A0A0 \
  --run 01H7B0B0B0B0B0B0B0B0B0B0B0 \
  --report ./reports/quality-cost.ts
```

CLI 形成 frozen Sample。每个 Measure 自己固定 expected member 与 total；某个 Attempt 没有可用值不会从分母消失。

## 编写报告

```tsx
import {
  aggregate,
  Bars,
  costUSD,
  defineReport,
  durationMs,
  Grid,
  model,
  passRate,
  Scatter,
  Table,
  type GroupFunction,
} from "niceeval/report";
import { qualityCostPricing } from "./pricing.ts";

const condition: GroupFunction = subject =>
  String(subject.run.experiment?.flags.condition ?? "unknown");

export default defineReport({
  title: "Quality and cost",
  pricing: qualityCostPricing,
  pages: [
    {
      id: "overview",
      path: "/",
      title: "Overview",
      render: async sample => {
        const rows = await aggregate(sample, {
          by: { model, condition },
          values: { passRate, durationMs, costUSD: costUSD(qualityCostPricing) },
        });

        return (
          <Grid>
            <Bars points={rows} x="model" y="passRate" color="condition" />
            <Scatter
              points={rows}
              x="costUSD"
              y="passRate"
              color="model"
            />
            <Table rows={rows} />
          </Grid>
        );
      },
    },
  ],
});
```

同一批 rows 同时进入表格和图形。两个组件读取同一份 MetricValue，而不是各自重新归并通过率或费用。全站路径关闭这些页面内容后，
view 与 static 读取同一 revision；`show` 对选中 Page 单独读取同一固定 Sample 的闭合值。`qualityCostPricing` 是同一 Report module
closure 中由 `definePricingProfile()` 声明并赋给 `ReportDefinition.pricing` 的 USD Profile；它不是 Runner 配置或运行期价格表。

## 读出状态

一个成本单元可以显示：

```text
$3.20 · 20 / 100 · partial
```

20 是 samples，100 是 total。partial 的 issues 指出未贡献成员，refs 提供复核路径。合法零成本保持 0，不会被误写成 empty。

passRate、durationMs 和 `costUSD(qualityCostPricing)` 可以各有不同 state。比如成本输入 unsupported 时，成本单元显示原因；质量单元仍可正常呈现。成本的 observed、estimated 与 unavailable slot-provider ledger 及有限 reasons 由 Analysis 签发，不能改用 Runner `estimatedCostUSD`。表格、终端文本和散点图的文字降级都必须保留这种差异。

## 交付

```sh
niceeval view \
  --run 01H7A0A0A0A0A0A0A0A0A0A0A0 \
  --run 01H7B0B0B0B0B0B0B0B0B0B0B0 \
  --report ./reports/quality-cost.ts
```

Scatter 的每个点都有同一批 rows 的文字或表格等价内容。每行显示 model、condition、质量、成本、samples、total、state 和可用 Evidence link；颜色和位置不是唯一信息载体。

view 启动时先枚举并构建完整 Report。任何详情 route、Source、Trace 或 Diff 都已是 ClosedSiteRevision 的页面或静态文件；
浏览器导航不会再次调用 Analysis。
