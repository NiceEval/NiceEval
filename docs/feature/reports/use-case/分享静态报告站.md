# 分享静态报告站

团队要把固定比较结果交给没有 Record、没有网络且不会安装 NiceEval 的读者。

## 定义详情路由

Attempt 详情使用一个参数化 Page。params 是页面作者维护的稳定 key codec；它以 durable Attempt locator 枚举实例，不能使用数组下标或显示 label。

```tsx
import {
  aggregate,
  defineComponent,
  defineReport,
  Download,
  Grid,
  Table,
  type PageEvidence,
} from "niceeval/report";
import { costUSD, model, passRate } from "niceeval/analysis";
import { attemptParams } from "./attempt-params.ts";

const EvidenceSummary = defineComponent(
  ({ evidence }: { readonly evidence: PageEvidence }) =>
    <Table
      caption="Evidence"
      rows={evidence.entries.map(entry => ({
        attempt: entry.attempt.locator,
        state: entry.state,
      }))}
    />,
);

export default defineReport({
  title: "Release report",
  pages: [
    {
      id: "overview",
      path: "/",
      title: "Overview",
      render: async sample => {
        const rows = await aggregate(sample, {
          by: { model },
          values: { passRate, costUSD },
        });

        const csvBytes = new TextEncoder().encode(renderQualityCsv(rows));
        return (
          <Grid>
            <Table rows={rows} />
            <Download
              file={{
                path: "quality.csv",
                mediaType: "text/csv; charset=utf-8",
                bytes: csvBytes,
              }}
            >
              Download quality data
            </Download>
          </Grid>
        );
      },
    },
    {
      id: "attempt",
      path: "/attempt",
      title: "Attempt",
      navigation: false,
      params: attemptParams,
      load: async (_sample, locator, context) => await context.evidence(locator),
      render: evidence => <EvidenceSummary evidence={evidence} />,
    },
  ],
});
```

attemptParams 的 enumerate(sample) 返回每个可公开详情的 durable locator。encode() 产生一个规范的小写 key，decode() 只接受同一规范 key。Host 对每个枚举值验证 encode、decode、再 encode 的往返，不接受重复、大小写碰撞或不规范 key。

## 生成完整站点

```sh
niceeval view \
  --report ./reports/release-summary.ts \
  --out ./release-report
```

--out 建立静态 all-pages execution。它运行 Overview，恰好调用 Attempt Page 的 enumerate(sample) 一次，并对全部得到的 locator 分别运行 load 和 render。每个详情 route 都是 execution 的固定部分；浏览器地址不能生成新参数、重新选择 Sample 或再次读取事实。

Host 收集全部 route、Download、host-data、runtime 和 manifest，再以同一个 collision set 检查冲突。它拒绝 exact path、ASCII case-fold、file/directory prefix、Windows device name、尾点、尾空格和长度冲突。

## 写出与完成标记

export 先预检闭合树、所有路径、下载和 execution problem。通过后才准备此前不存在的 release-report 目录，并按顺序写出：

1. HTML、host-data、downloads、manifest 和内建 runtime；
2. 所有静态页面与相对链接；
3. 最后的零字节 complete marker；
4. 目录 sync。

任何 execution problem 都使 export fail closed。已有目标目录，包括前次中断留下且没有 complete marker 的目录，都会返回 report-export-target-exists。Host 不删除、也不替换目标目录，并且不承诺原子目录发布。

## 断网读取

浏览器只消费目录内 artifact。runtime 不打开 Record、不加载 Report module、不调用 NiceEval，也不向网络请求详情数据。

MetricValue 的 partial、empty、unsupported 和 failed 会随页面与内建问题面写出。text、Web 和静态的无 JavaScript 页面都从同一 ClosedReportTree 派生，因此分母、issues、Evidence link 和状态一致。
