# 分享静态报告站

团队要把一个固定比较结果交给没有源 Record、没有网络且不会安装 NiceEval 的读者。

## 生成站点

    niceeval view \
      --latest \
      --report ./reports/release-summary.ts \
      --out ./release-report

命令选择 core-only Sample，由 ReportPlan 穷尽页面、参数化实例、Calculation、Download 与 inputs，形成 ReportInput 并执行一次 Report。成功后 <code>release-report</code> 是可直接由静态文件服务器提供的目录。

## 参数化页面

Attempt 详情、Experiment 详情或任何其它参数化页面必须在 plan 中给出每个具体 route。

    interface ReportPage {
      readonly id: string;
      readonly route: {
        readonly pathname: string;
        readonly parameters: Readonly<Record<string, string>>;
      };
    }

浏览器地址只打开已写出的页面。它不能依据 URL 新建参数值、重新选择 Sample，或向源 Record 请求另一个 Attempt。

## 穷尽文件清单

export 写出一个 <code>StaticAssetManifest</code>。清单至少包括：

- 所有预渲染页面；
- 每页当前组件宿主数据；
- 精确 runtime；
- exporter 内建的 runtime、基础样式与字体；
- 所有由页面提供的下载项。

用户 Report 不提供动态 <code>import()</code>、fetch、CSS、font、worker、WASM 或任意路径 loader。exporter 只写 ReportExecution 的既有结果与自身内建闭包。

每个 HTML、CSS、JS 与 data 引用都使用存在的相对路径。清单和目录不存在额外文件、网络 URL、绝对路径、路径越界或符号链接。

## 断网读取

浏览器只消费目录内的 artifact 私有数据。runtime 不打开源 Record，不调用 NiceEval，也不向网络请求事实或页面数据。删除本机的源 Record 不影响已发布静态报告站的阅读。

partial、unavailable 与 unsupported 状态随宿主数据一同写出。读者看到的分母、issues 和文字等价内容与 <code>show</code>、本机 <code>view</code> 相同。已请求 invalid 通道会使 export 失败，不生成可分享目录。

## 完整目录发布

目标目录必须不存在。export 先在目标同级、本次 owner 唯一的临时目录写入并检查所有文件。只有 manifest 与文件全部对应后，目标目录才以一次 rename 出现；它不替换或删除已有目录。
