# 分享静态报告站

团队要把一个固定比较结果交给没有源 Record、没有网络且不会安装 NiceEval 的读者。

## 生成站点

    niceeval view \
      --latest \
      --report ./reports/release-summary.ts \
      --out ./release-report

命令用 analysis selection 形成 bound handle 与 core-only Sample。Report 先闭合全部 `RecordProjection` declarations。宿主按 unique projection identity 形成一次 cached results，再按 typed values 展开 Calculation、PageFamily 与 Download，最后形成 immutable `ReportExecution`。成功后 `release-report` 是可直接由静态文件服务器提供的目录。

## 参数化页面

Attempt 详情、Assertion、conversation turn 或其它参数化页面由 PageFamily 从预先声明的 projected inputs 展开。展开完成后，每个具体 route 都成为 execution 的固定部分。

```ts
const assertionPages = definePageFamily({
  id: Either.getOrThrow(reportComponentId("assertions")),
  inputs: reportInputs({ assertions }),
  completeness: "allow-partial",
  instances: ({ inputs }) => assertionInstances(inputs.assertions),
  key: (instance) => instance.entryKey,
  route: (instance) =>
    Either.getOrThrow(reportRoute(`/assertions/${instance.entryKey}`)),
  render: ({ instance, inputs }) => assertionDocument(instance, inputs),
});
```

每个 Assertion 页的 route 依赖 Assertions Attachment 的 durable `entryId`，不是数组下标。PageFamily 的 instance value 不能追加新的 `RecordProjection`。浏览器地址只打开已写出的页面，不能依据 URL 新建参数值、重新选择 Sample 或向源 Record 请求另一个 Attempt。

## 写出与完成标记

export 只写这个 execution 的既有结果与内建闭包：所有预渲染页面、每页当前组件宿主数据、精确 runtime、exporter 内建的 renderer 与 problems page、所有由页面提供的下载项。用户 Report 不提供动态 `import()`、fetch、CSS、font、worker、WASM、任意 DOM 或路径 loader。

执行顺序：先 preflight execution problems 与 closure（任一 execution problem 整体不发布）；再向目标目录写出全部文件；最后写入零字节 `complete` marker 并 sync 目录。目标已存在返回 `report-export-target-exists`。

中断或失败可能留下没有 marker 的目录。host 以缺失的 marker 识别 incomplete output，提示用户删除后重试。本契约不承诺原子目录发布。

## 断网读取

浏览器只消费目录内的 artifact 私有数据。runtime 不打开源 Record，不调用 NiceEval，也不向网络请求 Attachment 或页面数据。删除本机的源 Record 不影响已发布静态报告站的阅读。

unavailable、unsupported 与 invalid 等 recorded data problems 随 semantic tree 和 host-owned problems page 一同写出，仍可成功导出。Web 与文字从同一棵树派生，因此分母、issues 与状态一致。Projector/author defect、非法 tree 或 route conflict 等 execution problem 会使 export 失败，不生成可分享目录。
