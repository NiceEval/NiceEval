# 分享静态报告站

团队要把一个固定比较结果交给没有源 Record、没有网络且不会安装 NiceEval 的读者。

## 生成站点

    niceeval view \
      --latest \
      --report ./reports/release-summary.ts \
      --out ./release-report

命令用 analysis selection 形成 bound handle 与 core-only Sample。Report 先闭合全部 `RecordProjection` declarations。宿主按 unique owner+projector 形成一次 cached results，再按 typed values 展开 Calculation、PageFamily 与 Download，最后形成 immutable `ReportExecution`。成功后 `release-report` 是可直接由静态文件服务器提供的目录。

## 参数化页面

Attempt 详情、Assertion、conversation turn 或其它参数化页面由 PageFamily 从预先声明的 projected inputs 展开。展开完成后，每个具体 route 都成为 execution 的固定部分。

```ts
const assertionPages = definePageFamily({
  id: "assertions",
  inputs: { assertions },
  completeness: "allow-partial",
  instances: ({ inputs }) => assertionInstances(inputs.assertions),
  route: ({ key }) =>
    Either.getOrThrow(reportRoute(`/assertions/${key}`)),
  render: ({ instance, inputs }) => assertionDocument(instance, inputs),
});
```

PageFamily 的 instance value 不能追加新的 `RecordProjection`。浏览器地址只打开已写出的页面，不能依据 URL 新建参数值、重新选择 Sample 或向源 Record 请求另一个 Attempt。

## 穷尽文件清单

export 写出一个 exact asset manifest。清单至少包括：

- 所有预渲染页面；
- 每页当前组件宿主数据；
- 精确 runtime；
- exporter 内建的 renderer、validated Theme tokens 与 problems page；
- 所有由页面提供的下载项。

用户 Report 不提供动态 `import()`、fetch、CSS、font、worker、WASM、任意 DOM 或路径 loader。exporter 只写 semantic report tree、`ReportExecution` 的既有结果与自身内建闭包。

每个 HTML、CSS、JS 与 data 引用都使用存在的相对路径。清单和目录不存在额外文件、网络 URL、绝对路径、路径越界或符号链接。

## 断网读取

浏览器只消费目录内的 artifact 私有数据。runtime 不打开源 Record，不调用 NiceEval，也不向网络请求 Channel 或页面数据。删除本机的源 Record 不影响已发布静态报告站的阅读。

partial、unavailable、unsupported 与 invalid 等 recorded data problems随semantic tree和host-ownedproblems page一同写出，仍可成功导出。Web与文字从同一棵树派生，因此分母、issues与状态一致。Projector/author defect、非法tree或route conflict等execution problem会使export失败，不生成可分享目录。

## 完整目录发布

目标目录必须不存在。export 先在目标同级、本次 owner 唯一的 staging directory 写入、验证并 sync 所有文件，再使用平台 atomic no-replace directory publish。目标存在、跨卷或 capability unsupported 都 fail closed；不得 fallback 到普通 rename、copy 或替换既有目标。
