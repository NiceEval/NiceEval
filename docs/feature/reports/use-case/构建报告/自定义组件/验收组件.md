# 验收自定义转换与 renderer

完成后至少核对：

- 普通 Result 可序列化，空值、部分数据和错误状态有明确输出；
- MetricValue 的 samples、total、basis 与 refs 没有丢失；
- 转换函数不读主题或终端宽度，不改写 Record 与 Sample；
- text / web 消费同一份值，两面都跑过 fixture；
- web 初始 HTML 无 JavaScript 时完整可读；
- renderer 使用主题令牌和稳定视觉身份，不自配颜色；
- 普通组合函数只返回已有组件树，不实现新的显示协议。

需要导航与下钻时，把组件装进[多页报告](../构建多页报告.md)。
