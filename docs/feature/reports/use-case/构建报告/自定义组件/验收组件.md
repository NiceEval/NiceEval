# 验收自定义 Source、Component 与组合

组件完成后至少核对：

- source 形态与手工 `compute()` 后的 data 形态 Content 深相等；
- 空数据、部分数据和错误状态都有明确输出；
- `MeasureCell` 的 samples、total 与 refs 没有丢失；
- 数据源不读主题或终端宽度，不改写 Record 与 Sample；
- Content 可序列化，Component 不提供 `resolve`，text / web 两面消费同一份 data；
- `dimensions()` 穷尽组件使用的维度值与编码，renderer 只通过 `ctx.dimension(handle).at(index)`
  读取名称与视觉编码，不自己拼复合键；
- 两面都跑过一遍：只跑 text 面抓不到 web renderer 用了未声明的值；
- web 面读取 `--niceeval-*` 令牌，组件 class 使用自己的前缀；
- Composition 只返回已有组件树，不实现 renderer。

需要完整页面导航与下钻时，把组件装进[多页报告](../构建多页报告.md)。
