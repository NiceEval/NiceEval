# 使用主题色与稳定身份

图表与实体列表使用完整分组值作为身份。
报告外壳的 `dimensionPins` 可以固定 Agent、Experiment 或自定义分组字段的视觉槽位。

公开 `RendererContext` 只有 locale 与 target，不提供颜色、线型或符号。自定义 renderer 从已交付的
完整 group identity 与显式 JSON options 产生稳定的语义 class / mark；web 样式再通过公开主题令牌
取色。它不能按数组下标取色、截路径末段，或读取 hex 后反推语义。

普通状态使用主题令牌：`accent`、`positive`、`negative`、`warning` 与中性面令牌。
需要新品牌体系时定义[报告主题](../../交付报告/主题/编写主题.md)。
