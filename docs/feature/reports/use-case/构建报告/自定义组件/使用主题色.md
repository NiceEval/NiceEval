# 使用主题色与维度呈现

Source 只产出稳定的维度值，不产出显示名或 hex 颜色。Component 通过 `dimensions(data)` 一次声明
自己消费的维度全集；管线收集整页值、消解重名与撞色后，renderer 再读取：

```tsx
const agent = ctx.present("agent", agentId);
return <span style={{ color: agent.color.css }}>{agent.label}</span>;
```

实验图始终以完整 experiment id 作为身份：

```tsx
const experiment = ctx.present("experiment", experimentId);
return (
  <span key={experiment.value} style={{ color: experiment.color.css }}>
    {experiment.label}
  </span>
);
```

自有 React 页面没有报告管线，调用 `presentDimension("experiment", experimentIds)` 一次传入本页
全集，再按完整 id 调用 `get()`。不能逐个计算标签或颜色，也不能用缩短后的显示标签充当身份。

`presentation.color.css` 是 `var(--niceeval-color-series-N)`，可以用于文字、背景、边框以及 SVG 的 fill / stroke。
不要按数组下标取色，不要拼公开 class 名，也不要读取浅色 hex；这些做法都会绕开页级消解或暗色主题。

需要新的品牌体系时定义[报告主题](../../交付报告/主题/编写主题.md)，不要在组件内部复制色板。
普通语义色直接读取 `--niceeval-color-accent`、`--niceeval-color-positive`、
`--niceeval-color-negative`、`--niceeval-color-warning` 与中性面令牌。
