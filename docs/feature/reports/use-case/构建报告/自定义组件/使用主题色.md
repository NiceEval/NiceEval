# 使用主题色与维度呈现

Source 只产出稳定的维度值，不产出显示名或 hex 颜色。Component 通过 `dimensions(data)` 一次声明
自己消费哪些维度值、用哪种编码；管线收集整页值、消解重名与撞槽后，renderer 按句柄取回：

```tsx
dimensions: (data) => ({
  agents: {
    dimension: "agent",
    encoding: { kind: "color" },
    values: data.rows.map((row) => row.agentId),
  },
}) as const,

web: (data, _options, ctx) => {
  const agents = ctx.dimension("agents");
  return data.rows.map((row, index) => {
    const agent = agents.at(index);
    return <span key={agent.value} style={{ color: agent.color }}>{agent.label}</span>;
  });
},
```

实验图始终以完整 experiment id 作为身份：把 `dimension` 写成 `"experiment"`，`values` 填完整 id，
renderer 用 `at(index)` 取回。标签由管线按整页 keyset 算成最短唯一后缀，不在组件里截路径末段。

自有 React 页面没有报告管线，调用 `presentDimension(declaration)` 传入同形状的声明，再按下标读取。
不能逐个计算标签或颜色，也不能用缩短后的显示标签充当身份。

`color` 是 `var(--niceeval-color-series-N)`，可以用于文字、背景、边框以及 SVG 的 fill / stroke；
`series` 编码另外给出可直接使用的 `strokeDasharray`、`marker` 与 `fill`。
不要按数组下标取色，不要拼公开 class 名，也不要读取浅色 hex；这些做法都会绕开页级消解或暗色主题。

需要新的品牌体系时定义[报告主题](../../交付报告/主题/编写主题.md)，不要在组件内部复制色板。
普通语义色直接读取 `--niceeval-color-accent`、`--niceeval-color-positive`、
`--niceeval-color-negative`、`--niceeval-color-warning` 与中性面令牌。
