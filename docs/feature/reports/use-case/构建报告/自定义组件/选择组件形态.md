# 选择普通函数、page 或 renderer

读取事实时，先在 plan 中声明 Projector 或 Calculation。
组织完整任务页面时，返回一个 `PlannedPage` 并让 `render(data)` 只消费已交付值。
只有现有原语组合不出的显示逻辑才使用 `defineRenderer()`。

不要仅为领域名词创建 renderer。
先判断 `Table`、`Grid`、`Callouts`、`Waterfall`、`Scatter` 等原语能否表达。
新 renderer 必须同时实现 text 与 web，并且不得读取 Store、请求 evidence 或重判可用性。
