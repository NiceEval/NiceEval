# 选择 Source、Component 或组合

需要读取 Sample、AttemptEvidence、artifact 或计算读数时，写 `Source`。需要显示一种新的 Content
形状时写 `defineComponent`；只把已有组件排列成业务区块时，写 `defineComposition` 组合函数。

不要仅为一个领域名词创建 renderer。先判断 `Table`、`Grid`、`Callouts`、`Waterfall`、`Chart`
等内建原语能否表达它；确实需要全新视觉形状时，用 `defineComponent` 同时实现 text 与 web 面。
作者组件进入报告树，但不进入 NiceEval 承诺维护的内建原语目录。
