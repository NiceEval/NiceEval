# 让多个原语共用一次计算

数据读取、聚合和排序只在 `source.compute(input)` 发生，产出中性 Content。同一 page 实例里的
多个原语直接引用同一个 source 对象；默认 input 也都是宿主注入的同一份 Sample：

```tsx
const byAgent = measureRows({
  rows: "agent",
  measures: [endToEndPassRate, costUSD],
});

return (
  <Col>
    <Table source={byAgent} />
    <Table source={byAgent}>
      <Column dataKey="agent" />
      <Column dataKey="cost-usd" />
    </Table>
  </Col>
);
```

resolve 按「source 对象 + input 引用」记忆化，所以这两个 `Table` 共用一次计算。报告外壳没有
source 注册表，原语也不接受字符串绑定。不同 page 独立 resolve；跨 page 复用的是同一份声明，
不是同一份计算状态。

这保证 text 与 web 消费同一份 Content，也避免一次 page 渲染重复扫描大文件。
