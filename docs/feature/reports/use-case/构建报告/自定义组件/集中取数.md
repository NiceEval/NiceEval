# 让多个组件共用一次计算

在 page render 中计算一次普通值，再传给多个组件：

```tsx
const byAgent = await aggregate(sample, {
  by: { agent },
  values: { passRate, costUSD },
});

return (
  <Col>
    <Scatter
      points={byAgent}
      x="costUSD"
      y="passRate"
      point="agent"
    />
    <Table rows={byAgent} />
  </Col>
);
```

同一个 page 实例只执行一次 render，text 与 web 消费同一棵结果树。
跨 page 复用普通任务函数，不共享隐式计算状态。
