# 让多个组件共用一次计算

在 `plan()` 中声明一次 Calculation request，再把同一 data key 交给多个组件：

```tsx
plan({ sample }) {
  const byAgent = aggregate(sample, {
    id: "by-agent",
    by: ["agent"],
    measures: { passRate, costUSD },
    unavailable: "exclude",
  });

  return {
    pages: [
      {
        id: "overview",
        title: "Overview",
        data: { byAgent },
        render({ byAgent }) {
          return (
            <Col>
              <Scatter points={byAgent} x="costUSD" y="passRate" />
              <Table rows={byAgent} />
            </Col>
          );
        },
      },
    ],
  };
}
```

`byAgent` 在 render 中仍是完整 `AggregateData`。Scatter 与 Table 的 aggregate overload 各自读取
同一个 EvidenceValue：available 时共用 `value.rows` / `value.coverage`，unavailable 时共用 causes
与 basedOn；所谓集中取数不包含一次私有 unwrap。

executor 以完整 identity 规范化和 memoize request。
text 与 web 共用同一树；不同 page instance 需要共享数据时，也显式引用同一个已计划 request，而不是靠异步函数源码猜等价。
