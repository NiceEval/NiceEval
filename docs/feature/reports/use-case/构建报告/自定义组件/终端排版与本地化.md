# 处理终端排版与本地化

Source 产出事实值、`unit` 与类型化 Cell；显示字符串经 `measureDisplay()` 一次生成，
写进 `MeasureCell.display`，Source 不自己截断或补空格。
两个面都读 `display` 而不从 `value` 重算，`show` 与 `view` 因此逐字相同。

自定义渲染组件必须自己实现 text renderer，并使用 `TextRenderContext` 的 `width`、`locale`、
`render` 与公开文本排版函数，按显示宽度而不是 JavaScript 字符串长度对齐——
中英文、emoji 和 ANSI 样式不能让表格错列。函数全集见
[格式化与呈现工具箱](../../../library/presentation.md)。

web 面中的 tooltip、折叠或 hover 详情在 text 面必须有可读降级，
不能返回空字符串或省略事实。宽度不足时的降级属于渲染组件，不属于数据源或组合组件。
