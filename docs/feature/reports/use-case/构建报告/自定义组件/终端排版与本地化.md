# 处理终端排版与本地化

MetricValue 的 available 分支保留 `value`、unit、format 与 verification；unavailable 分支保留
causes、coverage 与 basedOn，且没有 verification。
text 与 web renderer 按各自 locale 格式化，不把 display 字符串写回结果值。

公开 `RendererContext` 只有 locale 与当前 target，不存在另一套 `TextRenderContext`，也不暴露
viewport width。自定义 text renderer 返回语义 ReportNode，由 text 宿主负责最终换行与列宽；若组件
协议确实需要固定字符预算，作者把该预算作为显式 JSON options 交给两面，而不是从 context 猜终端。

web 的 tooltip、折叠或 hover 详情在 text 面必须有可读降级。
宽度不足时宿主可以换行或改成精确值表，不能静默省略事实。
