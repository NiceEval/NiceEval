# 把 NiceEval 读数和外部业务数据放进同一张表

## 解决什么问题

通过率和成本在 `.niceeval` 里，预算、工单、人工标注在别处。你要的是一张表同时有这两侧——
「哪个实验超了预算」「失败的题里有几道已经开了工单」。

## 全流程

1. **跑报告之前**把外部数据落成一份 JSON 快照：自己写脚本查 API、导出 CSV 转 JSON，随便什么方式。
2. `--data ./budgets.json` 指给这次运行，或写进 `config.reportData` 作为项目缺省。
3. 在 `defineComposition` 里用 `ctx.resolve(source)` 取 NiceEval 读数，用 `ctx.data` 读快照。
4. 用普通 JavaScript join 成一份可序列化 Content，交给 `Table` 的 `data` 形态。
5. 要多列就写 `<Column>` 子节点选字段，外部字段和官方读数在这一层没有区别。

```tsx
const BudgetReport = defineComposition(async (_props: {}, ctx) => {
  const performance = await ctx.resolve(sources.measure.rows({
    dimensions: ["experiment"],
    measures: [passRate, costUSD],
  }));

  return <Table data={joinBudgets(performance, ctx.data.budgets)}>
    <Column dataKey="experiment" />
    <Column dataKey="passRate" />
    <Column dataKey="costUSD" />
    <Column dataKey="budgetUSD" header={{ en: "Budget", "zh-CN": "预算" }} />
  </Table>;
});
```

## 边界

- **快照在报告之外准备。** 展开回调里不发起外部请求，也不读时钟、随机数或文件系统。
  报告承诺同输入同字节，`--out` 与本地 server 因此对同一份快照产出相同结果。
- **快照的新鲜度归你。** NiceEval 不知道你的预算表什么时候更新，也不替你缓存或失效。
- **外部字段不进 Source。** `Source` 只查 `.niceeval`；join 发生在 Composition，
  产物是普通 Content。
- 只想在自己的 React 页面里拼，不需要走报告树时，用
  [嵌入产品](../交付报告/嵌入产品.md)那条路——那里你本来就自己控制取数。
