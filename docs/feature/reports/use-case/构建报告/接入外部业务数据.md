# 把 NiceEval 读数和外部业务数据放进同一张表

先把业务数据 snapshot 进 Record，并写入 source、抓取参数、时间和完整 provenance。
报告再用一个 Projector 声明读取该 snapshot：

```ts
import { defineAttemptProjector } from "niceeval/record";

const utf8 = new TextEncoder();

function compareUtf8(left: string, right: string): number {
  const a = utf8.encode(left);
  const b = utf8.encode(right);
  const length = Math.min(a.length, b.length);
  for (let index = 0; index < length; index += 1) {
    if (a[index] !== b[index]) return a[index]! - b[index]!;
  }
  return a.length - b.length;
}

type BudgetInput = { month?: string };
type BudgetParameters = { month: string };

type MonthlyBudget = {
  readonly month: string;
  readonly limitUSD: number;
  readonly spentUSD: number;
};

const DEFAULT_BUDGET_MONTH = "2026-01";
const budgetDefaults: BudgetParameters = {
  month: DEFAULT_BUDGET_MONTH,
};

const budget = defineAttemptProjector<
  BudgetInput,
  BudgetParameters,
  MonthlyBudget
>({
  id: {
    namespace: "acme.finance",
    name: "monthly-budget",
    version: "1",
  },
  parameters: {
    schema: "acme.finance.monthly-budget/1",
    defaults: budgetDefaults,
    normalize(input = {}) {
      const unknownFields = Object.keys(input)
        .filter((field) => field !== "month")
        .sort(compareUtf8);
      const firstUnknown = unknownFields[0];

      if (firstUnknown !== undefined) {
        return {
          state: "invalid",
          issues: [
            {
              code: "unknown-field",
              path: [firstUnknown],
              expected: { kind: "known-field" },
            },
            ...unknownFields.slice(1).map((field) => ({
              code: "unknown-field" as const,
              path: [field],
              expected: { kind: "known-field" as const },
            })),
          ] as const,
        };
      }

      if (
        input.month !== undefined &&
        (typeof input.month !== "string" || input.month.length === 0)
      ) {
        return {
          state: "invalid",
          issues: [
            {
              code: "invalid-field",
              path: ["month"],
              expected: {
                kind: "schema-rule",
                id: "non-empty-budget-month",
              },
            },
          ],
        };
      }

      return {
        state: "success",
        parameters: { month: input.month ?? budgetDefaults.month },
      };
    },
  },
  dependencies: [],
  async projectNormalized(ctx, parameters) {
    const snapshots = await ctx.claims(budgetSnapshotQuery(parameters));
    return toMonthlyBudget(snapshots.value);
  },
});
```

这个签名与 [Record Library 的追踪式 Projector](../../../record/library.md#追踪式-projector) 相同。
它不传 raw Attempt；所有 identity、Claim 与 evidence 读取均经 `ProjectionReadContext`。
normalizer 只返回 `success` / `invalid` Result：unknown field 与非法 month 都产生稳定、非空的
`ProjectorInputIssue`，合法分支返回填满 default 的完整 `BudgetParameters`。它不 throw，也不返回
未包装的 parameters。

`MonthlyBudget` 与 `DEFAULT_BUDGET_MONTH` 是本用例定义的业务类型和固定默认值，不是 Reports 或 Record 的公共协议。
`defaults` 是完整规范化的 `BudgetParameters`；省略 request input 时 normalizer 收到空对象。
`dependencies` 声明实际 Projector object，本例没有 nested Projector，所以是空数组。

`projectNormalized()` 返回 raw `MonthlyBudget`，不能手写 available/unavailable；runtime 冻结
defaults、规范化参数、dependency 数组与结果，并从 tracked read 形成 `EvidenceValue`。

在 plan 中把 budget 和质量、成本 Calculation 一起列入 data request。
executor 形成带 basedOn 的 ReportData，页面只把它交给 `Table` 或图表。

业务系统、网络、进程变量、时钟和随机数不能在 plan 或 renderer 中读取。
业务值更新时，写入新的 Record revision、重新生成固定 Sample，再重新导出报告。

自有 React 页面使用同一份生成结果，见[嵌入产品](../交付报告/嵌入产品.md)。
