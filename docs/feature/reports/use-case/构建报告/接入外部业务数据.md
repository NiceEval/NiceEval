# 把 NiceEval 读数和外部业务数据放进同一张表

先把外部数据冻结成 JSON 快照，再通过 page render 的第二参数接收：

```tsx
export default defineReport<BudgetSnapshot>(
  async (sample, budgets) => {
    const performance = await aggregate(sample, {
      by: { experiment },
      values: { passRate, costUSD },
    });

    return <Table rows={joinBudgets(performance, budgets)} />;
  },
);
```

快照由 `--data` 或项目配置在运行前冻结。
page render 不请求网络，不读取环境变量、时钟或随机数。
join 是普通函数，外部字段不进入公共 Calculation。

自有 React 页面使用同一份转换结果，见[嵌入产品](../交付报告/嵌入产品.md)。
