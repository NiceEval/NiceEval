# `--history`：一道题时好时坏，按 Attempt 看固定历史

## 解决什么问题

默认报告回答固定 Sample 的汇总。
要解释某道 Eval 的历次执行，需要选择一份明确的历史 Sample，并将每个完整 AttemptRef 放进时间轴。

## 全流程

1. 用 eval 前缀和可选 `--exp` 选择历史 target：

   ```bash
   niceeval show security/check --history
   niceeval show security/check --exp compare/candidate --history
   ```

2. history plan 列出成员、Projection 和排序，再由 executor 生成时间、判定、摘要、MetricValue 与 refs。
3. 从任意行复制完整 locator target，继续查看详情、对话、时间树或 diff。
4. 需要跨 revision 趋势时，显式生成多个固定 Sample 并 union，再在报告中声明趋势 Calculation。

## 边界

- `--history` 与显式 `--report` 互斥，因为两者占据不同主 target。
- 历史 membership、配对和可比性都由输入 Sample/union 明确给出；host 不从配置、日期或目录猜规则。
- 无匹配或不可计划的 instance 会明确报错，不模糊回退。
