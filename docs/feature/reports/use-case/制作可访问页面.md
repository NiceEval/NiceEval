# 在 View 中审阅封口结果

用户需要在浏览器中审阅固定 Run overview，并按需查看 trace、diff、sources 或 artifacts。

```sh
niceeval view --run <run-id>
niceeval view @<attempt-locator> --no-open
```

未给 `--record` 时，View 从 Host 定位的 project operational Store 读取 sealed facts。它建立完整 revision 后才 ready；新 sealed Run 只提示更新，用户确认后才刷新。刷新失败保留 last-good，旧请求不会混入新 cutoff。

View 是 NiceEval 固定 UI。它不接收页面、样式、组件、路由或 renderer，也不形成静态目录。loopback session、Host 与 Origin 均经过验证。
