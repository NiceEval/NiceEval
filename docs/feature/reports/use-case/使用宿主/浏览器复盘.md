# 在浏览器里复盘一份固定样本

## 解决什么问题

终端适合快速分诊；人工需要图、层级表、详情 target 与主题时，使用 `view` 浏览同一份固定 Sample 的报告。

## 全流程

1. 打开报告：

   ```bash
   niceeval view
   niceeval view --no-open
   niceeval view --port 4400
   ```

2. host 打开固定 `RecordGraphRef`、materialize 单 source Sample、运行 plan 和 executor。
   浏览器导航、dialog 与 locale 只消费已生成的页面树。

3. 需要较小范围时，先按照 [收窄样本](../../../sample/use-case/收窄样本.md) 生成新 Sample，再把它交给 view 或 exportReport。

## 边界

- 位置参数、`--exp` 与 `--run` 是 host 的 Sample selection 输入；它们不会让 renderer 重选成员。
- `--record` 选择 Record，`--run` 选择 Run reference；详细路径见[选择另一份 Record 或 Run](选择Record与Run.md)。
- 同一固定 Sample 可用 `--out` 导出；导出规则见[静态站](../交付报告/导出静态站.md)。
