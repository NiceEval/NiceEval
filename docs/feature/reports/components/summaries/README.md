# 概览

这一组回答「这批结果有多大、整体是否健康、当前水位在哪」。`SampleSummary` 在组合层选择
snapshot 与 Measure 中的默认 KPI。`SampleOverview` 是内建首页的组合组件，装配摘要、
成本 × 主读数散点与 `sources.entity.experiments`。

完整契约见 [`SampleOverview`](sample-overview.md) 与 [`SampleSummary`](sample-summary.md)。
