# `PoweredBy`

唯一的品牌身份件，无 props。web 面渲染指向 niceeval 官网的一行品牌色小字
`Powered by NiceEval`；text 面零输出。它没有配置：用 [`Hero`](hero.md) / [`HeroCard`](hero-card.md) /
`PoweredBy` 就带品牌行，不想要品牌就不用这些身份件，用 `Col`、`Text` 等原语自行组合标题区。

```tsx
<PoweredBy />
```
