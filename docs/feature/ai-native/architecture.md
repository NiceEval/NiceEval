# AI-native：归属、不变量与效果评估

本页说明这条路径上每份文件归谁、哪些规则不能破，以及怎样知道它对 agent 真的有效。
打包与生成的仓库侧机制见[随包 AI 文档](../../engineering/agent-docs/README.md)，这里不重复。

## 每一跳的归属

| 文件或文本 | 单源 | 何时定稿 |
|---|---|---|
| 官网的一句话 | 产品站的首页组件 | 改动需要同步本功能的 [Format](format.md#那一句话) |
| `INIT.md` | 仓库根的 `INIT.md` | 随稳定版 tag 发布 |
| 托管区块与 skill 的文本 | Project Host 的 init 模板 | 随包发布，由 `niceeval init` 写入用户仓库 |
| `INDEX.md` 导语 | `INDEX.template.md` | 打包时与页面树拼合 |
| 页面树 | 各随包页面的 `title` 与 `description` | 打包时生成 |
| 随包页面 | `apps/docs-site/zh/**` | 打包时原样复制 |
| 类型声明里的用法说明 | 公开导出旁的源码注释 | 构建时进入声明文件 |

每份文本只有一个单源。托管区块与 skill 共用同一份正文；`INIT.md` 与随包的从零接入教程各管安装前与安装后，不互相复述。

## 不变量

- **一跳只指向下一跳（[T-32](../../taste.md#t-32)）。** 一句话只给 URL；`INIT.md` 只把 agent 送到 `INDEX.md`；项目指引只指向 `INDEX.md`。
  任何一跳都不复制下一跳的内容，所以下一跳改写时上一跳不需要跟着改。
- **`node_modules/niceeval/INDEX.md` 是唯一不变的路径。** 文档站可以任意重组；已经写进用户仓库的项目指引不因此失效。
- **安装后只读包内。** 安装完成后的每一份文档、参数说明和类型都来自已安装的包。
  随包页面不含通向另一个版本的链接。
- **安装前只读一份。** 安装前 agent 读到的只有 `INIT.md`，它来自稳定版 tag，不来自 `main`。
- **用户仓库里的写入有边界。** `init` 只写托管区块的标记之间和它自己的 skill 文件，其余内容不动。
- **读结果只走公开命令。** 项目指引与 `INDEX.md` 都要求 agent 用 `show`、`query` 与 `view`。
  公开命令给不出证据算产品缺口，由 NiceEval 修，不由 agent 读私有文件绕过。

## 失败时留下什么

| 失败点 | 留下的状态 | 恢复 |
|---|---|---|
| 读不到 `INIT.md` | 仓库没有任何改动 | 用户提供内容或允许联网后重来 |
| 安装成功、`init` 失败 | 依赖已在清单与锁文件里，没有项目指引 | 修正原因后重新运行 `init` |
| `init` 成功、接入中断 | 配置、空的 `evals/` 与项目指引 | 新对话经项目指引继续，见[在新对话里继续使用](use-case/continue-in-a-new-session.md) |
| 升级后没有刷新 | 旧措辞的项目指引，仍指向新版本的 `INDEX.md` | 运行 `init` 刷新 |

## 效果由评估给出 {#效果由评估给出}

这条路径的验收对象是 agent 的行为。独立的评估仓库用 NiceEval 评估“正在使用 NiceEval 的 coding agent”，对每个发布版本测量两族场景：

| 族 | 起始状态 | 回答的问题 |
|---|---|---|
| 安装 | 真实开源项目，只给那一句话和该版本的 `INIT.md` | agent 能否融入宿主工具链并跑通第一条真实评估 |
| 日常使用 | 已装好并初始化的项目 | agent 能否只靠随包文档运行、诊断、修复和编写评估 |

评估检查 agent 的文档读取顺序、是否读了实现源码或私有结果文件、交接是否与公开结果一致。
接入链路的评估设计见[安装评估](../../engineering/agent-docs/architecture/agent-install-eval.md)，
诊断链路见[诊断评估](../../engineering/agent-docs/architecture/agent-debug-eval.md)。

一个场景在多个版本上持续满分，说明它不再能区分文档的好坏；这时换成更难或更新的场景，而不是据此宣称文档已经足够好（[T-28](../../taste.md#t-28)）。
agent 在某一跳读错或绕路，修那一跳的文本或它指向的页面，不在评估仓库里给 agent 额外提示（[T-33](../../taste.md#t-33)）。
