# 把运行时坐标从 flags 迁出

隧道 URL 已经写进 `flags`，而它每次重启都换一个值。
把它改由 `ctx.fact()` 上报是正确的家（见[记录运行时坐标](记录运行时坐标.md)），但删掉这个键会改变 flags 袋，让上一轮的结果一次性失效。

搬迁那一次带上 `--accept config:flags.<键>`，授权命中这条差异的历史条目跨过它照常携带：

```sh
niceeval exp compare --accept config:flags.tunnelUrl
```

它做的是一次重锚：被携入的条目按本次口径重打指纹，下一次跑同一条命令自然命中，不必再带这个 flag。
selector 要命中本次计划里真实存在的差异；打错键名是空转，按启动期用法错误报出，并列出本次计划里可授权的原因。

风险留痕跟着结果走：被携入的条目记 `carriedAccepting`，写下跨过的 selector 与旧值新值摘要。
真正的评估条件不走这个入口——授权跨过它，等于把两批不可比的结果混进同一份报告。
