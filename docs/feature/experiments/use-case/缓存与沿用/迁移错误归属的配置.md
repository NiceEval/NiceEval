# 把运行时坐标从 flags 迁出

隧道 URL 已经写进 `flags`，而它每次重启都换一个值。
把它改由 `ctx.fact()` 上报是正确的家（见[记录运行时坐标](记录运行时坐标.md)），但删掉这个键会改变 flags 袋，让上一轮的结果一次性失效。

搬迁后先从历史里找出仍成立的那条结果，再显式接受它：

```sh
niceeval show --exp compare --history
niceeval accept @a1b2c3d4
```

它做的是一次重锚：这条结果按当前口径写入新的结果快照，下一次跑同一条命令自然命中。`@locator` 是唯一作用域；不会因为同一处 flags 差异而顺带接受其它评估用例。

风险留痕跟着结果走：新条目记 `acceptedFrom`，写下来源 locator、旧/新指纹与差异摘要。
真正的评估条件不走这个入口——授权跨过它，等于把两批不可比的结果混进同一份报告。
