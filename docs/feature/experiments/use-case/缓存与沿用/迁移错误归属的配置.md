# 把运行时坐标从 flags 迁出

隧道 URL 已经写进 `flags`，而它每次重启都换一个值。
把它改由 `ctx.fact()` 上报是正确的家（见[留存运行时坐标](留存运行时坐标.md)），但删掉这个键会改变 flags 袋，让上一轮的结果一次性失效。

搬迁后先从历史里找出仍成立的那条结果，再显式接受它：

```sh
niceeval show --latest --experiment compare --page adoption
niceeval accept @01J8ZK3M6P4T7V9X2C5N8QW0RY
```

它做的是一次明确采用：当前 Experiment 建立 Run，并用 `accepted` Member 引用同一个历史 Attempt。
完整 locator 是唯一作用域；不会因为同一处 flags 差异而顺带接受其它评估用例。

采用理由进入目标 Run 的 `niceeval.actions` 通道：它保存原 Attempt ref、当前配置 identity 与差异摘要。
Attempt 的 origin Run、Verdict、通道数据与 locator 都不变。
真正的评估条件不走这个入口——授权跨过它，等于把两批不可比的结果混进同一份报告。
