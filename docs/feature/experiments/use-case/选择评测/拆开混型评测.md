# 混合通过制与计分制 Eval

一个 Experiment 可以同时选中 `defineEval` 与 `defineScoreEval`。
运行与缓存共用同一实验配置，报告按 `EvalDescriptor.evaluationKind` 把通过率与 earned score 分列，绝不相加。

只有在两类题需要不同 agent、flags、预算或并发策略时，才按 tag、路径前缀或 `evaluationKind` 谓词拆成两个 Experiment；不是为了迁就读数类型。
语义见[计分粒度](../../../assertions/library/score-points.md)。
