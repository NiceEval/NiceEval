# 只限制撞限额的 Experiment

同一批实验里只有一个 Agent 服务频繁限流时，在该 Experiment 上设置 `maxConcurrency: N`，不要降低整次 Invocation 的全局上限。

该闸只限制本实验；其它实验继续使用全局并发。
限流 Attempt 退避时不会向本实验放行第 N+1 条，所以服务不会在已经限流时继续增压。
这个保证只覆盖本 Invocation；多开终端后各边上限相加，账户级配额用外部编排或分别调低每条命令的值。

该闸在 `PLAN` 行点名（`concurrency 19 (from flag) · mempal ≤1`）。
`--max-concurrency` 调大后并发仍上不去时，第一眼便知是哪个实验的闸在收（契约见 [CLI · live 面板](../../cli.md#运行中的-live-面板)）。

所有实验都受本机或 Provider 容量限制时，改用[全局并发](限制全局并发.md)。
