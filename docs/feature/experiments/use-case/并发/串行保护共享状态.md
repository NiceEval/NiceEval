# 串行保护跨 Attempt 共享状态

多个 Eval 会载入、修改并回存同一份宿主机文件或中心服务状态时，配置：

```ts
export default defineExperiment({
  maxConcurrency: 1,
  // ...
});
```

上一个 Attempt 的 teardown 和 Sandbox 销毁完成后，下一个 Attempt 才开始。实验级闸跨并行
Invocation 共用，因此 Hook 不需要再实现一把锁。状态的载入和回存放在
[Sandbox Hook](../生命周期/配置Sandbox-Hook.md)。

同一个闸的另一面是顺序:后一道 Eval 要读前一道写下的状态时,还得让队列按你要的次序排,见
[固定执行顺序](固定执行顺序.md)。
