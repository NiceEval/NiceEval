# 串行保护跨 Attempt 共享状态

多个 Eval 会载入、修改并回存同一份宿主机文件或中心服务状态时，配置：

```ts
export default defineExperiment({
  maxConcurrency: 1,
  // ...
});
```

上一个 Attempt 的收尾和 Sandbox 销毁完成后，下一个 Attempt 才开始。
实验级闸跨并行 Invocation 共用，因此生命周期代码不需要再实现一把锁。
跨 Attempt 的实际 Sandbox 目录、服务或快照都由 layer 的 `setup()` / `teardown()` 负责：创建后恢复、退休前回存。若要保护同一个连续实例，除串行外还要声明 `sandboxReuse: true`；新的 run 也在 `setup()` 处恢复 checkpoint。

同一个闸的另一面是顺序:后一道 Eval 要读前一道写下的状态时,还得让队列按你要的次序排,见 [固定执行顺序](固定执行顺序.md)。
