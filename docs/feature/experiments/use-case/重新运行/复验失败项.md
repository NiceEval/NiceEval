# 修复被测对象后只复验失败项

上一轮五条 Attempt 中一条 Verdict 为 `failed`。
修改 Agent prompt 或被测服务后，这类外部变化不一定进入指纹；直接重跑仍会把旧 Attempt 规划为可采用。

```sh
niceeval exp compare/bub-e2b --rerun
```

`--rerun` 只让旧 `failed` Attempt 不可自动采用，四条 `passed` Attempt 继续由 reference Member 引用，并在 actions 中写出 carried。
PLAN 因此显示四条 carried、一条 to run。
修好后不带 flag 再跑一次，应当全部沿用并确认整组为绿。

如果旧的 passed Attempt 也不可信，改用[全量重验](全量重验.md)。
