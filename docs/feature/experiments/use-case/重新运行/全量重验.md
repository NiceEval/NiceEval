# 外部环境变化后全量重验

Agent CLI 升级、同名镜像重建或被测服务行为变化时，旧的 `passed` 也可能不再可信。
先缩小选择，再关闭全部结果沿用：

```sh
niceeval exp compare/bub-e2b memory/commit0-cachetool --rerun all
```

计划内每条 Attempt 都会重新派发，本轮成本不含缓存摊薄。
新结果形成新的 Run，历史 Run 仍可在 `niceeval view` 中对照；确认无回归后，后续运行恢复默认沿用口径。

能长期表达成配置的外部差异应写入 `flags`，让指纹自然失效；`--rerun all` 只适合一次性复验。
