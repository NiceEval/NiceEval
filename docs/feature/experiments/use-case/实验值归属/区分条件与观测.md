# 按角色区分条件与运行时观测

同一个值可能有两种角色。
以服务版本 `0.10.39` 为例：

- 实验声明“这一组必须使用 0.10.39”时，它是条件，写进 `flags`；换版本应让旧 Attempt 失去采用资格。
- 运行时向服务询问“实际是什么版本”时，它是观测。只有 NiceEval 已发布 typed collector 或 Adapter 能力能接纳这类语义时，才进入 Record catalog 中与 owner 匹配的 fixed family；没有 collector 的第三方值不自动持久化或查询。

判断依据不是值长什么样，而是谁在什么时候决定它。
不要只把实验条件上报成观测，否则条件变化后旧 Attempt 仍可能被采用。

提交与携带规则见 [Record · Architecture](../../../record/architecture.md)。
