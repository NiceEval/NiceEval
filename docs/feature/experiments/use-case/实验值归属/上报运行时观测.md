# 上报运行时观测

记忆服务由 setup 启动，隧道 URL 每次运行都可能变化。
这个值在启动完成后才知道，因此不写进 `flags` 或 `labels`，而在 Attempt 作用域上报：

```ts
writeEnv(): SandboxCommand {
  return async (sandbox, context) => {
    context.fact("com.example.nowledge-endpoint", env!.url);
    await sandbox.writeBytes(".nowledge/env", new TextEncoder().encode(`NMEM_URL=${env!.url}\n`));
  };
}
```

URL 作为 Attempt fact 随 Record 保存。
Report 以同名 requirement 经 reader 读取它；默认运行反馈不复制这类细节。完整 document 超过 65,536 UTF-8 bytes 时写入失败，大内容必须使用专用 Attempt channel 与 blob。
它不参与指纹；被采用的 Attempt 保留 origin Run 的值，不会被本轮地址替换。

如果地址本身是作者指定的评估条件，应改用[flags](声明运行条件.md)，否则条件变化后旧结果可能被错误沿用。
