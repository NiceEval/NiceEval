# 上报运行时观测

记忆服务由 setup 启动，隧道 URL 每次运行都可能变化。
这个值在启动完成后才知道，因此不写进 `flags` 或 `labels`。producer 先定义 Attempt-owned typed Channel：

```ts
const nowledgeEndpoint = defineJsonChannel({
  owner: "attempt",
  name: "com.example.nowledge-endpoint",
  schemaId: "com.example.nowledge-endpoint/v1",
  schema: NowledgeEndpointSchema,
});
```

拥有 Attempt scope 的 command 再写入 payload：

```ts
writeEnv(): SandboxCommand {
  return async (sandbox, context) => {
    context.record(nowledgeEndpoint, { url: env!.url });
    await sandbox.writeBytes(".nowledge/env", new TextEncoder().encode(`NMEM_URL=${env!.url}\n`));
  };
}
```

URL 作为 Attempt Channel payload 随 Record 保存。Report 用对应 `ChannelProjector` 读取 typed view；默认运行反馈不复制这类细节。

自定义 JSON payload 超过 schema 或 Record byte limit 时写入失败。大内容使用专用 Attempt Channel 与 blob。
它不自动参与 input/config identity。被采用的 Attempt 保留 origin Run 的值，不会被本轮地址替换。

如果地址本身是作者指定的评估条件，应改用[flags](声明运行条件.md)，否则条件变化后旧结果可能被错误沿用。
