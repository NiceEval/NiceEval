# 制作可访问页面

维护者需要打开本机 Insight，先看可比较的 Experiment 全貌，再安全进入具体 Run：

```sh
niceeval view
```

命令在 session、SPA assets 与只读 transport 都准备好后才打开浏览器。Worker 固定一个 `PublicationCutoff`；Header
右上角先显示 `Experiments` selector，再显示 `Language`。切换 selector 会更新 Results 与 URL，同时保留当前语言。

## 观察启动与关闭

```text
$ niceeval view --no-open --port 43173
niceeval view — open in a browser:
http://127.0.0.1:43173/?session=local-session
```

URL 中的 session material 只留在本机。浏览器关闭或收到中断后，View 关闭 listener、失效 session 并释放读取资源。
脚本可指定独占端口、等待 HTTP 可用，并用进程退出码和 stderr 观察终态；View 不维护另一套 lifecycle machine stream。

Results 显示 Summary cards、指标、Experiment 比较、成本 × 通过率或分数散点图，以及 Experiment → 可选 Eval 路径组 → Eval →
Attempt table。散点图以成本为横轴，以已关闭的通过率或分数为纵轴。Run identity 作为 Attempt provenance 保留，并可打开 exact
Run debugger。页面组件不另写 SQL，不重算成员、分母、成本或指标。

`active` Run 已发布 Attempt 立即可见，空 slot 显示 pending。发现更新时页面只提示；用户确认后才在新的
`PublicationCutoff` 准备结果并原子切换。失败时旧页面继续可读。中英语言切换不影响 cutoff、identity、URL 或结果。

主仓 Preview 使用仓库合成 Run facts，只做第一方 UI dogfood，不取得本机 session 或真实项目数据。
