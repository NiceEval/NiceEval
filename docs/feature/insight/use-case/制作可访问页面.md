# 制作可访问页面

维护者需要从一致的完整 RecordSnapshot 打开本机 Insight，先看可比较的 Experiment 全貌，再安全地进入具体
Run。这个页面是 React SPA，浏览器经本机 session 读取 SQLite，而不是下载一份业务 JSON。

```sh
niceeval view
```

命令在 session、SPA assets 与 SQLite GET 都准备好后才打开浏览器。NiceEval Header 右上角固定先显示
`Experiments` selector，再显示 `Language`。根 URL 没有显式选择时，repository 按稳定顺序选定默认
Experiment；切换 selector 会更新 Overview 与 URL，同时保留当前语言。

## 观察启动与关闭

人读模式只在 View 准备完成后写出固定的两行入口；URL 中的 session material 只应留在本机终端：

```text
$ niceeval view
niceeval view — open in a browser:
http://127.0.0.1:43173/?session=local-session
```

`--no-open` 只改变是否请求 OS 浏览器，不改变 ready 的 Human 输出；维护者可在本机复制同一 URL：

```text
$ niceeval view --no-open --port 43173
niceeval view — open in a browser:
http://127.0.0.1:43173/?session=local-session
```

浏览器关闭或收到中断后，本次 View 会关闭 listener、失效 session 并关闭 Snapshot delivery；Human 模式不追加
`closed` 行。脚本只消费 `--json` 的一行一个 event；对应成功、关闭和启动失败的完整 NDJSON
见[固定输入并选择要审阅的 Run](审阅一次Run怎样采用结果.md#固定输入并选择要审阅的-run)。

Overview 先显示 Summary cards 与指标，再显示 Experiment 比较。
Experiment → 可选 Eval 路径组 → Eval → Attempt 层级 table 显示每层范围和下一层入口。Run identity 作为
Attempt member 的 selected provenance 保留，不另建 Run 层。比较、指标与 table 直接由 worker 中的集中
typed repository 读取同一份 Snapshot，页面组件不另写 SQL 或重算一套业务结果。

维护者可使用：

```sh
niceeval view --record <snapshot>
```

该命令读取已验证的 Snapshot，固定其 exact Seal，不发现更新。没有 `--record` 的 operational View 可以
发现新的 sealed publication，但只显示更新提示；用户确认后才形成完整新 Snapshot 并原子切换。刷新失败时，
当前 last-good Overview 保持可读。切换成功后，每个 logical slot 只显示新 generation 选出的 latest member；
同 slot 的旧 Run member 被替换，不与新 member 同时保留。

中英语言切换只改变 UI 文案。它不影响 Snapshot、Experiment identity、URL、指标或比较结果。

主仓 Preview 的相同页面只读取仓库合成 fixture Snapshot。它用于第一方 dogfood，既不会取得本机 session，
也不会读取维护者的真实 Record。
