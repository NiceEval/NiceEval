# 制作可访问页面

维护者需要从一致的完整 RecordSnapshot 打开本机 Insight，先看可比较的 Experiment 全貌，再安全地进入具体
Run。这个页面是 React SPA，浏览器经本机 session 读取 SQLite，而不是下载一份业务 JSON。

```sh
niceeval view
```

命令在 session、SPA assets 与 SQLite GET 都准备好后才打开浏览器。NiceEval Header 右上角固定先显示
`Experiments` selector，再显示 `Language`。根 URL 没有显式选择时，repository 按稳定顺序选定默认
Experiment；切换 selector 会更新 Overview 与 URL，同时保留当前语言。

Overview 先显示 Summary cards 与指标，再显示 Experiment 比较。Experiment → Eval → Run → Attempt 层级
table 显示每层范围和下一层入口。比较、指标与 table 直接由 worker 中的集中 typed repository 读取同一份
Snapshot，页面组件不另写 SQL 或重算一套业务结果。

维护者可使用：

```sh
niceeval view --record <snapshot>
```

该命令读取已验证的 Snapshot，固定其 exact Seal，不发现更新。没有 `--record` 的 operational View 可以
发现新的 sealed publication，但只显示更新提示；用户确认后才形成完整新 Snapshot 并原子切换。刷新失败时，
当前 last-good Overview 保持可读。

中英语言切换只改变 UI 文案。它不影响 Snapshot、Experiment identity、URL、指标或比较结果。

主仓 Preview 的相同页面只读取仓库合成 fixture Snapshot。它用于第一方 dogfood，既不会取得本机 session，
也不会读取维护者的真实 Record。
