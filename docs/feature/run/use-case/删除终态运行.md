# 删除终态运行

## 用户目标

删除一个不再需要的 Run，同时避免破坏其它 Run 对其 Attempt 的引用。

## 起始状态

用户在保存 Record 的项目目录中，已经选定待删除 Run 的完整 ID。
本篇命令未实际运行，以下均为预期输出说明。`<run-id>` 替换为实际完整 ID。

## 完整路径

1. 删除前打开目标 Run，核对身份和状态。 {#inspect}

   ```sh
   niceeval show run:<run-id>
   ```

   预期输出：确认 Experiment 与目标一致，Run 为 `completed`、`interrupted` 或 `failed`。
   若还是 `active`，先核实 owner；旧 owner 已终止时走 [恢复中断运行](恢复中断运行.md)，再回到这里。

2. 请求删除，并在确认提示中核对目标。 {#delete}

   ```sh
   niceeval run delete <run-id>
   ```

   预期输出：终态且没有 incoming reference 时，删除成功。
   存在 incoming reference 时零删除，并列出依赖 Run 与 Attempt locator；用户据此保留目标或另行检查依赖。
   已确认目标的脚本可以使用 `niceeval run delete <run-id> --yes --json`。

3. 再列出项目中的运行。 {#verify}

   ```sh
   niceeval run list
   ```

   预期输出：成功删除的 Run 不再出现在列表中；若前一步拒绝，目标仍保留。

## 结果

仅在安全条件满足时删除选定 Run。命令不提供 force、cascade 或 selector 批量删除路径。

| 阻断条件 | 处理 |
|---|---|
| 目标为 `active` | 不删除；先处理活动 owner 或安全恢复 |
| 其它 Run 存在 incoming reference | 不删除；按命令返回的依赖定位，不绕过引用保护 |
| ID 无效或 Run 不存在 | 从列表核实 exact ID，不把前缀当作目标 |
