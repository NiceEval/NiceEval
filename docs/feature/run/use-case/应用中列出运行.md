# 应用中列出运行

## 用户目标

在自己的 Node 应用中展示一个项目的 Run 列表，使用公开 API 取得领域值。

## 起始状态

应用已安装 `niceeval` 与 `effect`，在已有 Record 的项目目录中运行。
本篇调用未实际运行，以下输出为预期输出；完整 API 与失败形状由 [Run Library](../library.md) 拥有。

## 完整路径

1. 在应用入口导入 `runHost`，构造当前项目的列表操作。 {#construct}

   ```ts
   import { Effect } from "effect";
   import { runHost } from "niceeval/run/host";

   const listing = runHost.list({ cwd: process.cwd() });
   ```

   预期结果：得到惰性的 Effect；仅构造它不读取项目，也不获取运行资源。

2. 在应用最外层执行，并展示返回的 Run ID。 {#execute}

   ```ts
   const page = await Effect.runPromise(listing);
   console.log(page.runs.map((run) => run.runId));
   ```

   预期输出：该项目 Run ID 的数组；没有 Run 时数组为空。
   每次执行都独立取得并关闭所需资源，调用者不用额外提供 NiceEval runtime 或 Scope。

## 结果

应用收到 `RunListResult`，可用领域值构建列表。后续查看、删除与恢复的调用形状继续使用 Library 中的具名操作。
读取失败走 `RunReadError`；应用按 Library 的 typed failure 处理，失败时不伪装成空列表。
