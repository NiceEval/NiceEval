# `--reuse-sandbox` —— 用例

`--reuse-sandbox` 仍会真实执行每条 Attempt，只把同基线批次放到一条热道上，省掉重复的
Sandbox 创建与公共安装。它不是缓存，也不会让复用结果进入后续缓存或 CI。

| 目标 | 用例 |
|---|---|
| 本地快速冒烟一批 Eval | [把 N 次冷启动折成一次](批量冒烟.md) |
| 同一题重复运行并观察稳定性 | [安装只付一次](重复运行看稳定性.md) |
| 选中的 Eval 不共享基线 | [根据报错缩小批次](异构批次.md) |
| 现有 Eval 还不能安全进入热道 | [准备可串行复用的 Eval](准备可复用评测.md) |

完整契约见[串行复用](../../serial-reuse.md)。
