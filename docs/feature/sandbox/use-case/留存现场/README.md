# `--keep-sandbox` ——用例

`--keep-sandbox` 为某次真实 Attempt 留下可进入的 Sandbox 现场。
先按要回答的问题选用例：

| 目标 | 用例 |
|---|---|
| setup 或 agent 启动阶段报错，落盘证据不足 | [进入现场重跑 setup](环境启动错误.md) |
| 怀疑 agent 修改了 workdir 之外的状态 | [检查全局环境](检查工作目录外状态.md) |
| 一个失败有多个假设，不想每次冷启动 | [在同一现场反复验证](现场验证假设.md) |

完整 CLI 契约见[留存现场](../../cli.md)。
