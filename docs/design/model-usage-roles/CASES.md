# Cases

| Case ID | 用户问题 | 固定输入 | 验收结果 |
|---|---|---|---|
| C1 | 两实验只改一个用途 | 三用途模型配置，只改第一项 | 展示精确差异，不把组合拼成一个模型名 |
| C2 | 网关转发与模型回退 | 同一用途两次物理调用，不同实际模型；provider 可未知 | 两次均保留，transport 与 serving provider 分列 |
| C3 | 费用缺口 | 375 次调用，356 次 reported USD 0.071083152，19 次未知 | partial 小计，不宣称完整总价；明确报告的零是已知 |
| C4 | 裁判计费 | 应用调用、一次 Judge 重试、一次失败且 usage 缺失 | 两类分列，物理重试独立计数，总费用保留缺口 |
| C5 | 历史读取 | 无用途配置或无裁判物理用量的旧 Record | 展示未登记，不用当前配置或价格补造 |
| C6 | 单模型 Agent | 原来一个 model 的实验 | 作者仍能简洁使用，计划与实际含义一致 |
| C7 | 大量调用 | 超过 128 次，多模型、失败和重试混合 | 聚合包含全部，分页不会改变分母 |
| C8 | 未调用用途 | 已配置用途没有已登记物理调用 | 配置仍可见，明确 no-recorded-calls，不制造零费用调用 |
| C9 | 截断后识别未调用用途 | a 有 129 个模型组，z 有 1 调用，unused 无调用 | 配置行全账本计数为 129/1/0，不由两个预览缺席推断 |
