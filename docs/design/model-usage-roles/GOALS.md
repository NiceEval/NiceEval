# Goals

## G1: 可解释的模型配置

一个实验使用多个命名用途。读者能区分计划模型与实际物理调用模型，不通过拼接模型名表达组合。
普通单模型 Agent 保持简洁；游戏、工作流与多 Agent 应用使用同一中立机制。

## G2: 可核对的费用

按实际用途、serving provider、model 汇总应用调用。被测应用与评估裁判分列，也能读取不重复计费的合计。
reported 优先且保留零；估算有封存的显式价格证据；未知费用不成为零。

## G3: 唯一账本

作者不汇总应用 journal，也不为 NiceEval 复制请求正文。Adapter 上报物理调用事实，框架负责统计与展示。
失败、取消、重试和替代模型都保留。未知字段与统计范围必须可见。
