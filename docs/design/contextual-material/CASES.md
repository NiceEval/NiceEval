# 消费场景

| Case ID | 输入与问题 | 验收结果 |
|---|---|---|
| C1 | 一个 NPC 的决策、另一个 NPC 的发言 | 同项组合不能拼成成功 |
| C2 | 全部台词包含错误、无人听见的原文 | 默认全部保序参与质量问答 |
| C3 | 双方问路对话与后续移动 | 两份问答复用完整对话；听闻、采用、会面分别判断 |
| C4 | 澄清搬运、合理拒绝、静默协作 | 交流与真实操作分开；静默不成为失败条件 |
| C5 | 全部操作含失败、拒绝和调整 | 全组裁判；接受不冒充执行完成 |
| C6 | 实际请求、返回、物理重试和未采用选择 | 正文、顺序、丢弃原因与所有物理调用保留 |
| C7 | 非游戏 Agent 工具与消息 | 同一材料 Match 与问答契约；core 不认识业务字段 |
| C8 | 完整空集、partial、超预算的整组问答 | 空集失败且零调用；其它 QA 不可判定且不截断 |
| C9 | 不同 Adapter、Attempt、后来被修改的 ctx | 类型拒绝不兼容 ctx；独立快照与 owner 阻止串证据 |
| C10 | 失败请求、缺失 token、实扣零和混合币种 | 官方账本统计；未知小计不能通过上限 |
| C11 | 多次读取用量、运行耗时与游戏时间 | getter 每次新快照；旧变量不变；业务时钟另判 |
| C12 | 恶意台词、伪造引用、取消与资源释放 | 台词仅为数据；引用受校验；关闭后不读应用 ctx |
| C13 | 至少 1000 条正式操作，包括失败、拒绝和未采用回执 | 显式捕获预算允许完整捕获；全部命中保序交给一次裁判，公开 detail 可完整读回 |
| C14 | 双方完整 180 秒对话，有效与错误发言混合 | 正文与稳定身份全部保留，公开 detail 可完整读回，不采样或缩短观测时段 |
| C15 | 大读取集合、小命中组，与小捕获预算、大 Judge 预算 | 前者可评估；后者不能用未穷尽集合冒充全量材料 |
| C16 | 容量停止前有见证，或没有见证 | 前者存在性通过并保存未穷尽收据；后者不可判定，均零模型调用 |
| C17 | 合法捕获容量、选中材料容量、审计容量、Attempt 保留容量分别耗尽 | show 直接区分具体拒绝原因，未知不补零 |
| C18 | 完成边界与业务时间从 ctx 计算成单个小事实 | 一个 ScoreMatch、一个评分断言；只捕获边界、指标与证据身份 |
| C19 | 单个聚合事实包含多个明细，或完成边界缺失 | 不逐项平均；未知事实不运行 scorer 或模型 |
