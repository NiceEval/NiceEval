# Goals

## G1: 完整调用事实

统计 NiceEval 向 Judge 发起的每次 HTTP 传输，包括失败、重试和中断。拒绝发送的逻辑步骤不计物理调用。
没有调用、调用后数量未知、明确零和明确费用分别表达，QA Verdict 不影响账本。

## G2: 共用读面

Agent 与普通 Adapter 使用同一机制。Query、两个 Show 入口与 View 消费相同封存事实。
应用费用保持独立，总费用按币种汇总已知金额并指出缺项。

## G3: 可追查且有界

每项能定位 origin Attempt、Assertion 和传输序号。保留费用证据和显式估价证据；不公开凭据或任意响应正文。
取消、超限和历史缺源不能被解释为零调用或零费用。

## G4: 离线验收

用真实 HTTP 边界 fixture、安装候选和公开读取证明行为，不新增付费调用或重写历史 Record。
