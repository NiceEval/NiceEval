Report authors use one plain TypeScript data flow:

```text
Sample or AttemptEvidence
  → plain functions
  → serializable result values
  → components
  → text / web
```

The public API has no unified lazy query object.
Async reads and computation happen in the page render; components only display already-computed values.

## Define a report

Pass a render function for a single-page report:

```tsx
export default defineReport(async (sample) => {
  const rows = toExperimentRows(sample);

  return (
    <Col>
      <Table rows={rows} />
    </Col>
  );
});
```

Declare `pages` statically for a multi-page report:

```ts
interface SamplePage {
  id: string;
  title: LocalizedText;
  input?: "sample";
  navigation?: boolean;
  render: PageRender<Sample>;
}

interface AttemptPage {
  id: string;
  title: LocalizedText;
  input: "attempt";
  navigation: false;
  render: PageRender<AttemptEvidence>;
}
```

`pages` is a non-empty ordered array. Each `id` must be unique.
A report has at most one Attempt page, and it must set `navigation: false`.
The host runs only the requested page render.

Shell fields are only `title`, `theme`, `dimensionPins`, `head`, and `pages`.
Compose footer and header links with ordinary components; component script styles are declared with custom renderers.

## Calculation

Calculations come from `rollup()`:

```ts
const changedLines = rollup(
  async (attempt) => {
    const diff = await attempt.diff();
    return diff ? countChangedLines(diff) : null;
  },
  {
    withinEval: min,
    acrossEvals: mean,
    unit: "lines",
    better: "lower",
  },
);
```

Reducers are function values. Built-in entries include:

```ts
mean;
sum;
min;
max;
percentile(0.95);
```

Omitted within-eval or across-eval reducers default to `mean`.
`null` does not participate in reducers; empty sets stay `null`.

Built-in and user Calculations use the same `rollup()`.
Common built-ins include `passRate`, `costUSD`, and `durationMs`.

## `aggregate()`

`aggregate()` runs multiple Calculations by grouping function:

```tsx
const performance = await aggregate(sample, {
  by: {
    agent,
    experiment,
  },
  values: {
    passRate,
    costUSD,
  },
});
```

The result is a plain read-only array:

```ts
readonly {
  agent: string;
  experiment: string;
  passRate: MetricValue;
  costUSD: MetricValue;
  refs: readonly AttemptLocator[];
}[];
```

Keys in `by` and `values` must not collide or use the reserved key `refs`.
Custom grouping can be any ordinary synchronous function that returns a string.

## `MetricValue`

```ts
interface MetricValue {
  value: number | null;
  unit?: string;
  format?: MetricFormat;
  better?: "higher" | "lower";
  bounds?: {
    min?: number;
    max?: number;
  };
  samples: number;
  total: number;
  basis: "attempt" | "eval" | "run" | "pair";
  refs: readonly AttemptLocator[];
}
```

`value: null` means missing or not applicable, not zero.
`samples`, `total`, and `basis` explain the denominator.
`refs` let tables, charts, and agents drill down to source Attempts.

Use `metricValue()` and `evidenceRow()` for complex algorithms that need evidence:

```ts
const point = evidenceRow({
  eval: evalId,
  delta: metricValue({
    value,
    samples,
    total,
    basis: "pair",
    evidence,
    unit: "%",
  }),
});
```

Paired deltas, stability, fixed-suite scorecards, and historical trends live beside their reports.
They do not share one public function without a stable formula.

## Entity projection

Entity projection runs immediately:

```ts
toAttemptRows(attempts);
toExperimentRows(sample);
toEvalRows(sample);
await toTraceNodes(sample);
toSampleNotices(sample);
```

Functions return exact result shapes, not a unified wrapper.
Plain arrays can still be `filter()`ed, `toSorted()`, `slice()`d, or joined.

Thin components exist for high-frequency entities:

```tsx
<AttemptList attempts={attempts} />
<ExperimentList sample={sample} />
<EvalList sample={sample} />
```

## Component props

| Component | Main props |
|---|---|
| `Table` | `rows` |
| `Scatter` | `points`, `x`, `y`, `point` |
| `Line`, `Bars`, `Area` | `points`, `x`, `y` |
| `Stat` | `value` |
| `Grid` | `items` |
| `Callouts` | `items` |
| `Conversation` | `turns` |
| `Waterfall` | `nodes` |
| `SourceView` | `source` |
| `DiffView` | `files` |
| `AttemptDetails` | `attempt` |

`SourceView`'s `source` is the source value to display.
It is not a lazy query object.

## Tables

```tsx
<Table
  rows={performance}
  columns={[
    "agent",
    { field: "costUSD", label: "Spend" },
    "passRate",
  ]}
/>
```

When `columns` is omitted, fields are derived in stable order.
Sort, filter, and limit only change displayed rows; they do not re-aggregate.

## Charts

```tsx
<Scatter
  points={performance}
  x="costUSD"
  y="passRate"
  point="agent"
/>
```

Points derived from a Sample must carry row-level `refs`,
and metric fields must be `MetricValue`.
Pure external numeric series must declare `external` explicitly and provide no Attempt drill-down.

Use `Line` for time or ordered numeric axes, `Bars` for rankings and stacks,
and `Area` for cumulative or interval quantities.
Use `ComposedChart` when you need mixed marks; bind each series to fields and axes explicitly.

## Attempt detail

Attempt detail is one parameterized page:

```tsx
{
  id: "attempt",
  title: "Attempt",
  input: "attempt",
  navigation: false,
  render: (attempt) => (
    <AttemptDetails attempt={attempt} />
  ),
}
```

Custom detail pages can call explicitly:

```ts
toConversationTurns(attempt);
toDiffFiles(attempt);
toTimelineNodes(attempt);
toAttemptSource(attempt);
```

The official export `standardAttemptPage` reuses the full detail page when placed in your `pages` array.

## Custom renderer

Use the extension entry only when you need a new display shape:

```tsx
import { defineRenderer } from "niceeval/report/extension";

const ConfusionMatrix = defineRenderer({
  text(value, options, context) {
    return renderTextMatrix(value, options, context);
  },
  web(value, options, context) {
    return <WebMatrix value={value} options={options} />;
  },
});
```

Both `text` and `web` are required.
Renderers only accept already-computed plain values; they do not read Sample, Record, artifacts, or the network.

Put scripts and styles in `assets`.
Initial HTML must remain fully readable without JavaScript.

## React entry

`niceeval/report/react` exports only pure web components and result types:

```tsx
const points = await aggregate(sample, {
  by: { agent },
  values: { passRate, costUSD },
});

<Scatter
  points={points}
  x="costUSD"
  y="passRate"
  point="agent"
/>
```

The server or build process opens the Record, selects the Sample, and computes results.
The browser only receives serialized values.
