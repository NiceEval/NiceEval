Result viewing starts with published Runs. NiceEval selects a scope before it provides a `Sample` to a Report Page or component callback. Application code does not open result storage and cannot construct a `Sample`.

To inspect results in a terminal or browser, see [Viewing Results](/tutorials/viewing-results). To define Pages and components, see [Report API](/reference/report-components).

## A Sample retains the selected scope

A `Sample` fixes the Runs, logical positions, and denominator for one selection. Its snapshot retains the state of each position:

| State | Meaning |
| --- | --- |
| `included` | An analyzable Attempt exists. |
| `not-recorded` | A planned position has no result. |
| `core-invalid` | The position's identity or reference cannot be read reliably. |
| `excluded` | The current selection explicitly excluded this position. |

`--run` retains the complete planned scope of a named Run. `project-current` retains only the scope that still matches the current project. Neither selection silently shrinks its denominator because a Measure is missing data.

Use a `Sample` with `aggregate()`, `query()`, or `narrowSample()` only while a Page, `load()`, or composite component is executing. After the callback returns, the page retains only the closed values it already received and cannot begin another read.

## Use published Analysis inputs

`niceeval/analysis` exports NiceEval's published inputs and domain-view requests. Authors can use these inputs in `defineMeasure()`, but cannot register arbitrary data sources, durable data types, or readers.

```ts
import {
  attemptEvidenceView,
  query,
} from "niceeval/analysis";
import { defineComponent, Text } from "niceeval/report";

const EvidenceCount = defineComponent(async (_props, { sample }) => {
  const evidence = await query(sample, {
    kind: "domain-view",
    view: attemptEvidenceView,
  });

  return Text({ value: `Inspectable evidence entries: ${evidence.entries.length}` });
});
```

`attemptPassed`, `attemptLatencyMs`, and `attemptToolFailure` are the currently public Measure inputs. `attemptEvidenceView`, `attemptObservabilityView`, `fileChangesView`, `sourcesView`, and `sandboxHistoryView` provide closed domain views that cannot be reduced to a table.

When you need a new long-lived result, first check whether NiceEval already provides a suitable Eval, Experiment, Adapter, or analysis capability. A callback has no general write or registration API. Arbitrary JSON, network responses, or current files cannot become a new analysis input.

## Get table and chart rows with aggregate()

`aggregate()` forms `ClosedRows` from established Dimensions and Measures. Each row retains a stable identity, and every Measure cell is a complete `MetricValue`.

```ts
import { aggregate } from "niceeval/analysis";
import { defineComponent, Table } from "niceeval/report";
import { experiment, passRate } from "./quality-measures.ts";

const ResultTable = defineComponent(async (_props, { sample }) => {
  const rows = await aggregate(sample, {
    by: { experiment },
    values: { passRate },
  });

  return Table({ rows });
});
```

`Table` reads `rows`. `Bars`, `Line`, and `Scatter` read `points`. `Stat` reads a complete `MetricValue`. A display layer can sort, limit, or filter visible rows, but it cannot recalculate a Measure from the displayed array or reduce `MetricValue.total`.

## Understand closed states

A Measure's `MetricValue.state` tells you whether its result is complete:

| State | Meaning |
| --- | --- |
| `available` | Every denominator member contributes under the Measure's rule. |
| `partial` | A displayable result exists, but some members did not contribute. |
| `empty` | The inputs are complete and the domain result is validly empty. |
| `unsupported` | The current environment does not support the input. |
| `failed` | Reading, joining, or aggregation failed. |

`value: 0` is still a valid reading, not `empty`. `samples` is the actual contributor count. `total` is the denominator the Measure set in advance. Problems and evidence references travel with `MetricValue`, `ClosedRows`, and domain views into a Report.
