After a run completes, select the Run you want to inspect from a quiescent Record. `show` presents it in the terminal, while `view` serves it locally in a browser. Both commands use the same path:

```text
Record reader → Sample → ReportInput → show or view
```

The Sample determines the comparison scope and denominator. ReportInput carries the Sample state, requested channels, and completeness into a Report. A Report does not read files directly.

## Select Runs to inspect

Select one explicit Run:

```sh
npx niceeval show --run 01J9ZK3M6P4T7V9X2C5N8QW0RY
```

Or select the final completed Run for each target Experiment:

```sh
npx niceeval show --latest --experiment checkout
```

The latest policy considers completed Runs only. To inspect an unfinished Run, pass its complete ID with `--run`.

## Inspect results in the terminal

`show` renders the default Report's text content. Supplying a page or Report still creates ReportInput from the same Sample.

```sh
npx niceeval show --run 01J9ZK3M6P4T7V9X2C5N8QW0RY --page overview
npx niceeval show --latest --experiment checkout --json
```

`--json` writes calculated page data and status; it does not open a second data path. To inspect one Attempt, select a planned Attempt page inside the selected Sample:

```sh
npx niceeval show --run 01J9ZK3M6P4T7V9X2C5N8QW0RY \
  --page attempt-01J8ZK3M6P4T7V9X2C5N8QW0RY
```

## Inspect results in the browser

```sh
npx niceeval view --latest --experiment checkout --no-open
```

The local server serves one fixed ReportInput. Later file edits do not change its pages. After editing a Record or Report, end the command and run `view` again.

## Read denominators and channel states

A Sample preserves a Run's complete expected-slot denominator. Each slot can be:

| State | Meaning |
| --- | --- |
| `included` | It has a valid Member and readable Attempt. |
| `not-recorded` | A planned slot has no Member. |
| `invalid` | The Member, Attempt, or core reference has a problem. |
| `excluded` | This selection excluded it. |

Pages and Calculations also show the state of requested channels. `unavailable` means the channel was not collected or does not apply; `unsupported` means the reader does not support it; `invalid` shows a named issue and fails the request that depends on it. A partial reading must show its observed count, denominator, and a `partial` marker.

## Reread after an edit

A Record is editable current data. When the directory is quiescent, you can edit a Verdict, Usage, or another channel value. Run `show` or `view` again after the edit; the new Sample uses the current value.

On a single Record root, the Runner, an active reader, the export phase that selects a Sample and builds ReportInput, and manual editing are mutually exclusive. Once the reader releases the Record, Report execution and site writing can continue because they no longer access it.
