sidebarTitle: "Debugging"
description: "Use visible errors, Sample states, and rebuild feedback to diagnose viewing, rerun, and export problems."
---

Start by reading the problem through an explicit Run. Do not guess the target from a directory name or time.

```sh
npx niceeval show --run <run-id>
npx niceeval view --run <run-id> --no-open
```

These commands form a Sample from the same scope and execute the same Report. Confirm that the selection is right before inspecting Measures and problems on the page.

## Results cannot be found or opened

| Visible error | Meaning | Next step |
| --- | --- | --- |
| `record-root-missing` | The selected result set does not exist. | Check the project directory or `--record`. |
| `record-migration-required` | Published results need migration. | Run `niceeval migrate`. |
| `record-format-unsupported` | The current NiceEval does not recognize the result format. | Install NiceEval that supports that format. |
| `core-invalid` | A position's identity or reference cannot be read reliably. | Read the named problem; do not treat it as a missing result. |

Published results have no manual-edit repair path. Create a new Run when you need different facts. Run `niceeval clean` to remove incomplete remnants.

## An expected result is missing from the Sample

A Sample preserves a Run's expected denominator. Check each position's state on the page:

| State | Meaning | Next step |
| --- | --- | --- |
| `included` | An analyzable Attempt exists. | Check the Measure or evidence the Report shows. |
| `not-recorded` | A planned position has no result. | Check whether the Invocation completed, or rerun that scope. |
| `core-invalid` | The position's identity or reference has a problem. | Address the named problem; do not treat it as uncollected. |
| `excluded` | This selection excluded the position. | Check `--experiment`, `--eval`, or another selection condition. |

To see what the next run will do, first run:

```sh
npx niceeval exp checkout --dry
```

The output shows whether every position will execute or adopt an existing Attempt, and lists why carry conditions are not met.

## A Measure or detail is incomplete

Measures and domain views bring their own state and problems to a page:

| State | Meaning | Next step |
| --- | --- | --- |
| `partial` | A displayable result exists, but some denominator members did not contribute. | Inspect the problem and denominator; do not treat it as complete. |
| `empty` | Inputs are complete and the domain result is validly empty. | Confirm that this empty result fits the task. |
| `unsupported` | The current environment does not support the required input. | Use an environment that supports it, or view a page that does not depend on it. |
| `failed` | Reading, joining, or aggregation failed. | Read the named problem and fix its cause. |

Run `niceeval migrate` before reading historical results that need migration. A Measure problem does not change the Sample's established denominator or prevent unrelated pages from displaying.

## view does not show new results

Each successful `view` rebuild publishes a new `ReportExecution`. If a Report, configuration, theme, or result change makes a rebuild fail, the page continues to show the previous usable execution and displays the current problem.

Fix the rebuild problem, then wait for the next successful rebuild. A page refresh cannot bypass that boundary or make an old execution reread results.

## JSON has no receipt

`npx niceeval exp <experiment> --json` writes its final receipt only after it successfully creates an Invocation. If an input error exits before that, there are no `runIds` to inspect.

Correct the Experiment, Eval selection, or command argument, then run it again. On success, use the receipt's `runIds` with `show`, `view`, or `view --out`.

## A static report site cannot export

`view --out` exports only one completed `ReportExecution`. Analysis problems can appear in the exported site. An author callback that throws, an invalid semantic tree, or a route conflict stops export.

The target directory must not exist. After a failure or interruption, use a new output directory and export again.

See [Viewing Results](/tutorials/viewing-results) and [Publish a Static Report](/tutorials/publish-report) for the complete workflows.
