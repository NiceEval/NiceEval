Runner 把选中的 Experiment 和 Eval 排成一次 Invocation。它在当前进程中安排执行、显示进度，并把停稳后的业务事实写入 Record。

## Invocation、Run 与 Attempt

一次 Invocation 有一个 `invocationId`。每个选中的 Experiment 建立一个 Run；Run 的 expected slots 决定本次分母。

每个 slot 最多有一个 Member：

- `executed`：Runner 实际执行了 Attempt。
- `carried`：规划器采用了已有 Attempt。
- `accepted`：操作者显式采用了已有 Attempt。

Attempt 保留自己的 `origin`，即实际执行它的 Run 与 slot。`carried` 和 `accepted` 只引用 Attempt，不复制它的 Verdict、Usage、事件或其他业务值。

## 执行前的规划

`niceeval exp --dry` 在停稳的 Record 上列出每个 slot 的计划。它会读取规划所需的 Verdict 与 Eligibility，决定是执行还是采用已有 Attempt。

```sh
npx niceeval exp checkout --dry
```

carry 只在终态、输入身份、超时和 `--rerun` 条件都合适时发生。身份是带 domain 的不透明值，只有 domain 相同的值才比较。理由、资格和当时的输入信息写入目标 Run 的 `niceeval.actions` 通道。

规划完成后，Runner 才启动需要执行的 Attempt。详情见[重跑与沿用](/zh/tutorials/rerun-and-cache)。

## 当前进程反馈

运行时的进度、活动 Attempt 和短诊断只服务当前进程。终端可以显示它们，`--json` 也会输出相同的机器可读反馈。

```sh
npx niceeval exp checkout --json
```

`exp --json` 输出 NDJSON。progress 与 diagnostic 行描述当前 Invocation；它们不是 Record 的解码格式。最后恰好一行是轻量 `InvocationReceipt`：

```json
{
  "type": "receipt",
  "receipt": {
    "invocationId": "01J8ZK3M6P4T7V9X2C5N8QW0RY",
    "runIds": ["01J9ZK3M6P4T7V9X2C5N8QW0RY"],
    "startedAt": "2026-08-09T10:00:00.000Z",
    "completedAt": "2026-08-09T10:01:00.000Z",
    "completion": "completed"
  }
}
```

receipt 只说明本次调用的身份、Run、时间与完成状态。需要 Verdict、Usage、诊断或报告聚合时，用其中的 `runIds` 重新读取停稳的 Record。

## Reporter

Reporter 只接入当前 Invocation。它可以把当前进程已知的结果交给外部系统；`--junit` 也会写出供 CI 平台读取的文件。

这些输出不拥有 Record。Verdict、Usage、断言与诊断仍由停稳 Record 的具名通道保存。需要在后续步骤查看完整结果时，使用 receipt 的 `runIds` 选择 Sample，再运行 `show`、`view` 或 `view --out`。

## 停稳后查看

Runner 结束后，用明确 Run 选择查看结果：

```sh
npx niceeval show --run 01J9ZK3M6P4T7V9X2C5N8QW0RY
npx niceeval view --run 01J9ZK3M6P4T7V9X2C5N8QW0RY --no-open
```

`show` 和 `view` 都先选择 Sample，再形成固定的 `ReportInput`。如果用户修改停稳 Record，结束当前查看命令后再次执行，新的调用会读取修改后的值。

## 结束状态

进程退出状态反映这次 Runner 已知的 Verdict、执行错误和 Invocation completion。CI 可以用退出状态决定是否通过；机器调用方可以读取最后的 receipt，再用 `runIds` 选择要显示或导出的结果。

没有建立 Invocation 的输入错误没有 receipt。此时先修正命令、Experiment 或选择条件，再重新运行。
