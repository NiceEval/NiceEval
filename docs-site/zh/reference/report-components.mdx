## 固定调用链

```ts
let plan: ReportPlan;
let input: ReportInput;
{
  await using record = await openRecordReader({ root });
  const sample = await selectSample(record, selection);
  const scope = createReportScope(sample);
  plan = definition.plan(scope);
  input = await buildReportInput({ record, sample, plan });
}

const execution = executeReport({ definition, plan, input });
```

只有 `buildReportInput()` 接收 `RecordReader`。Report 定义、Calculation、Page、Download、view 和静态 runtime 都不接收 reader 或路径。

## ReportScope

```ts
interface ReportScope {
  readonly selection: RunSelection;
  readonly runs: readonly SampleRun[];
  readonly slots: readonly SampleSlot[];
}
```

`runs` 穷尽全部已选 Run，`slots` 是完整 core-only 分母，保留 `included`、`not-recorded`、`invalid` 和 `excluded`。included slot 带 Attempt ID、origin、locator 和 Member kind，但没有业务 facts。

## FactRequirement

```ts
type FactOwner = "run" | "attempt";

interface FactRequirement<Value> {
  readonly id: string;
  readonly owner: FactOwner;
  readonly name: string;
  readonly source: BuiltInFactSource | CustomJsonFactSource<Value>;
}
```

内建 source 只能由 NiceEval 导出。自定义事实使用：

```ts
defineJsonFact({
  id,
  owner,
  name,
  parse(document) {
    return value;
  },
});
```

自定义 document 精确为 `{ observedAt, value }`，media type 为 `application/json`。同一 owner/name 只有一个值；parser 不接收 bytes、路径或 blob。build 只验证 transport，execute 才对每个 owner 与 requirement 组合调用一次同步 parser。

## ReportPlan

```ts
interface ReportPlan {
  readonly calculations: readonly Calculation<unknown>[];
  readonly pages: readonly ReportPage[];
  readonly downloads: readonly ReportDownload[];
}
```

plan 没有顶层 facts 或 resources。每个 consumer 自己声明 inputs；参数化页面必须在 plan 中列出每个具体 route。

## ReportInput

```ts
interface ReportInput {
  readonly scope: ReportScope;
  readonly sample: Sample;
  // 内部 fact matrix 使用未导出的 brand，用户代码不可索引。
}

interface ReportContext {
  readonly scope: ReportScope;
  readonly sample: ReportSample; // 明确不含 recordRoot
}
```

每项内部读取保留 `ChannelRead` 的 `read | unavailable | unsupported | invalid` 与完整度。consumer 只拿到 fact-free context，以及验证自己 `inputs` 的 `readRun(runId, fact)` 和 `readAttempt(includedSlot, fact)`；不同 requirement 对象不能复用 id。

context 中的 `sample` 是不含 `recordRoot` 的 `ReportSample` projection。Calculation、Page 和 Download 都无法从公开字段取得 Record 路径。

## Calculation

```ts
interface Calculation<Value> {
  readonly id: string;
  readonly inputs: readonly FactRequirement<ReportJsonValue>[];
  readonly completeness: "allowPartial" | "requireComplete";
  evaluate(input: CalculationInput): CalculationValue<Value>;
}
```

Calculation 只能读取自己的 inputs。`allowPartial` 保留完整 denominator 与实际 observed；`requireComplete` 要求 durable collection 与 decoding 均 complete。

## Page

```ts
interface ReportPage {
  readonly id: string;
  readonly route: ReportRoute;
  readonly title: string;
  readonly inputs: readonly FactRequirement<ReportJsonValue>[];
  readonly calculations: readonly Calculation<unknown>[];
  render(input: ReportPageInput): ReportPageModel;
}

interface ReportPageModel {
  readonly title: string;
  readonly body: ReportJsonValue;
  readonly textAlternative: string;
}
```

PageModel 是普通可序列化数据。颜色、图形或交互不能替代文字、表格与状态说明。

## Download

```ts
interface ReportDownload {
  readonly id: string;
  readonly path: ReportDownloadPath;
  readonly mediaType: string;
  readonly inputs: readonly FactRequirement<ReportJsonValue>[];
  readonly calculations: readonly Calculation<unknown>[];
  build(input: ReportDownloadInput): Uint8Array;
}
```

Download 通过 `defineReportDownloadPath("downloads/...")` 创建路径，并在唯一执行阶段完整生成 bytes，不在 export 时重新运行。

## ReportExecution

```ts
interface ReportExecution {
  readonly plan: ReportPlan;
  readonly input: ReportInput;
  readonly calculations: readonly CalculationResult<unknown>[];
  readonly pages: readonly PageResult[];
  readonly downloads: readonly DownloadResult[];
}
```

每种 result 都区分成功、`input-invalid` 与 `execution-failed`。`executeReport()` 对每个 consumer 最多执行一次。view 局部显示失败，export 对同一 execution 全量 preflight。

Calculation result 携带原 Calculation 引用，并与 plan 中的顺序一一对应。

## StaticAssetManifest

```ts
interface StaticAssetManifest {
  readonly routes: readonly {
    readonly route: ReportRoute;
    readonly pagePath: StaticOutputPath;
    readonly hostDataPath: StaticOutputPath;
  }[];
  readonly entries: readonly StaticAsset[];
}
```

manifest 固定为 `manifest.json`，并且不把自身列入 entries；除此之外每个文件都必须恰好有一个 entry。静态目录只含已经生成的页面、host-data、downloads 与 exporter 内建 runtime、基础样式和字体。

page 与 host-data 文件名按 plan 顺序产生；内建资源只在 `runtime/`，用户下载只在 `downloads/`。route 与输出 path 都使用最长 240 bytes 的 canonical ASCII 段；比较 key 固定为逐 byte ASCII lowercase，并在创建临时目录前统一检查 exact/key 重复和目录前缀冲突。

`exportStaticReport({ execution, out })` 要求 out 不存在。它不会替换已有目录，也不会执行 Report 代码、读取 Record、访问网络或查找任意用户路径。
