Record 是 `.niceeval/record/` 下可携带、可进入 Git 的 opaque 目录。应用代码不读取内部结构或写入
其中的文件，也不 import Record reader / writer。选择运行和执行 projection 由 `niceeval show`
与 `niceeval view` 的内部 host 完成。

要在终端或浏览器中查看结果，请阅读[查看结果](/zh/tutorials/viewing-results)。要定义页面和
计算，请阅读[报告 API](/zh/reference/report-components)。

## Classic facade 读取深冻结样本

classic facade 的组件经 `ctx.scope` 读取深冻结的 `ClassicSample`。它是 host 按固定 projection plan 一次投影后构造的只读样本，不携带 reader、路径或延迟 I/O。`aggregate(ctx.scope, { by, values })` 在 Eval 级分组，`passRate` 按两级分母计算并显式呈现 coverage。

`ClassicSample` 的 metadata 标注来源。`project-current` 使用完整 current-declaration profile，显示 `metadataOrigin: "current-declaration"` 与 current-not-historical notice。`--run` 的 explicit-runs 在 Record 没有 durable profile 时，metadata 是 unknown / partial，experiment id 回退为 id / unknown，并给出一条结构化 notice。历史数据不读取当前项目声明，也不与当前项目字段混合。

## Report callback 收到 AnalysisSample

Report 的 Calculation、Page 与 PageFamily callback 收到一份纯 `AnalysisSample`。它保存
selection 已建立的每个 expected slot 和完整分母，不包含路径、reader、文件句柄或延迟 I/O。
`--run` 使用具名 Run 的完整 expected slots；`project-current` 只把身份仍匹配当前目标的 slots 纳入 Sample：

| 状态 | 含义 |
| --- | --- |
| `included` | 有合法 Member，指向精确 Attempt。 |
| `not-recorded` | expected slot 没有 Member。 |
| `core-invalid` | Member、Attempt 或核心引用不能可靠读取。 |
| `excluded` | host 在已有 Sample 上明确排除了该项。 |

作者可以从 `niceeval/report` 导入必要的 Sample / identity 类型，也可以对已有 Sample 使用纯
`narrowAnalysisSample`。这些值不能恢复 Record I/O。

## 用官方 projector 声明数据

Report 作者选择 NiceEval 提供的 opaque projector，再声明它怎样与 Sample 对齐：

```ts
import {
  attemptSlotProjection,
  selectedRunProjection,
  evaluationsProjector,
  verdictProjector,
} from "niceeval/report";

const verdicts = attemptSlotProjection(verdictProjector);
const evaluations = selectedRunProjection(evaluationsProjector);
```

`attemptSlotProjection` 对每个 slot 形成 entry。`attemptOriginRunProjection` 仍对每个 slot
形成 entry，但使用 Attempt 的 origin Run。`selectedRunProjection` 对每个 selected Run
形成 entry。

作者不能定义 raw Attachment family/projector，不能接收 payload 或 blob capability，也不能
直接调用 projection runtime。需要新的持久事实时，由 NiceEval 提供新的高层 projector 或
未来独立设计的 Eval / Experiment / Plugin 能力。

## Projection 结果保持穷尽

前两种 slot projection 保留 `excluded`、`not-recorded`、`core-invalid` 与
`attachment-result`。Attachment result 再表达：

| 状态 | 含义 |
| --- | --- |
| `available` | 官方 projector 已形成 typed value。 |
| `unavailable` | owner 没有请求的事实。 |
| `migration-required` | 需要运行 `niceeval migrate`。 |
| `migration-unavailable` | 历史事实不能无损形成当前值。 |
| `unsupported` | 当前 NiceEval 不认识该事实版本。 |
| `invalid` | 已记录的数据无法可靠解释。 |

这些是 Report 可显示的数据状态，不会改变 Sample 的 Core 状态。I/O、权限、reader Scope 与
raw schema errors 留在内部 host；公开作者面只收到自包含值和结构化 Report problem。
