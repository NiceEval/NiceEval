`Record` 是 `.niceeval/record/` 下可人工编辑的当前数据集。它保存 Run、Member、Attempt 和各自的具名通道。读写都只在目录停稳时进行。

这页说明数据边界。要在终端或浏览器中查看结果，请阅读[查看结果](/zh/tutorials/viewing-results)。要定义页面和计算，请阅读[自定义报告](/zh/tutorials/custom-reports)。

## 打开停稳的 Record

Library 接收实际的 Record 根目录，不会补接 `.niceeval` 或 `record`。先打开 reader，再用明确的 Run 选择形成 `Sample`。

```ts
import { openRecordReader } from "niceeval/record";
import { selectSample } from "niceeval/sample";

let sample: Sample;
{
  await using reader = await openRecordReader({
    root: ".niceeval/record",
  });

  sample = await selectSample(reader, {
    kind: "runs",
    runIds: ["01J8ZK3M6P4T7V9X2C5N8QW0RY"],
  });
}
```

也可以使用 `latest` policy。它从每个匹配 Experiment 的已完成 Run 中选择最后一个；未完成的 Run 必须以 `runIds` 明确选择。

```ts
let latest: Sample;
{
  await using reader = await openRecordReader({ root: ".niceeval/record" });
  latest = await selectSample(reader, {
    kind: "latest",
    experimentIds: ["checkout"],
  });
}
```

每次读取都使用调用时的文件值。用户在目录停稳后修改 Verdict、Usage 或其他通道，再次构造 ReportInput 时会读取修改后的值；Sample 本身只保存核心和分母。

## 核心数据关系

```text
Run 的 expected slots
        ↓
Member: executed | carried | accepted
        ↓
Attempt 与它的具名 channels
```

- Run 的 `expectedSlots` 决定分母。
- 一个 slot 最多有一个 Member。`executed` 表示本 Run 执行了 Attempt；`carried` 与 `accepted` 表示采用已有 Attempt。
- Attempt 保留实际执行它的 `origin`。采用 Attempt 不复制 Verdict、Usage 或诊断。
- carry 与 accept 的理由属于 Run 的 `niceeval.actions` 通道，并以 slot 与 Attempt 关联。

Record 的结构、路径、身份和引用校验用于拒绝自相矛盾的数据。它不保存编辑历史。

## 通道读取状态

业务值保存在具名通道，例如 Verdict、Eligibility、Usage 与诊断。通道的持久采集完整度和这次解码完整度是两条独立信息。

| 状态 | 含义 | 调用方处理 |
| --- | --- | --- |
| `read` | 已读到值；采集或解码仍可能是 partial。 | 保留完整度与问题说明。 |
| `unavailable` | 已声明但未采集，或此处不适用。 | 显示原因。 |
| `unsupported` | 当前 reader 不支持这个通道。 | 只让依赖该通道的内容受影响。 |
| `invalid` | 被请求的通道文件或内容无效。 | 以具名问题失败。 |

未知或退役通道只在该通道显示 `unsupported`。`unavailable`、`unsupported` 与 `invalid` 不能互相替代。未请求的通道不会阻止无关读取。

## 从 Sample 到 ReportInput

`Sample` 是内存中的明确选择，不会写回 Record。它保留每个 expected slot，并用下列状态表达范围：

| Sample 状态 | 含义 |
| --- | --- |
| `included` | 有合法 Member，且能读取其采用的 Attempt。 |
| `not-recorded` | expected slot 没有 Member。 |
| `invalid` | Member、Attempt 或核心引用存在问题。 |
| `excluded` | 调用方在既有 Sample 上排除了该项。 |

Reports 根据所需的 facts 把 Sample 变成 `ReportInput`。`ReportInput` 是进程内普通值，保留分母、成员状态、通道读取状态和问题。Report 只消费它，不读取路径或自行解释文件。
