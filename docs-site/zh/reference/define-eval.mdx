`defineEval` 是编写评估用例的主要入口。每个评估用例文件调用一次，传入描述和 `test(t)`，并默认导出结果。

```ts
import { defineEval } from "niceeval";

export default defineEval({
  description: "Brooklyn weather query",
  async test(t) {
    const turn = await t.send("What's the weather like in Brooklyn today?");
    t.check(turn.succeeded());
  },
});
```

<Note>
  不要提供 `id` 或 `name`。[NiceEval](https://niceeval.com/) 从文件路径推导评估用例 ID。
</Note>


#### `diff`

```ts
diff?: { include?: string[]; ignore?: string[] };
```

调整 agent diff 的归因排除清单(仅 Sandbox 型;见 docs/feature/eval/README.md):两个数组都是

合成规则固定为「默认 ∪ ignore,再被 include 打洞」,清单在分类账锚点时冻结。

## Test context: `t`

`t`（`TestContext`）是评估用例作者拿到的高层上下文。`t` / Turn / Session 的事件方法、`t.sandbox` 的文件方法和 Judge recipe 只生成 Fact。`t.check(...)`、`t.checkIfCovered(...)` 与 `t.require(...)` 决定这些事实怎样影响通过制判定；值加 Match 的写法会原子创建并消费 Fact。`t.require(...)` 只接受已经可求值的 `phase: "now"` Fact，失败时中止后续代码；`phase: "final"` 的文件与最终 diff Fact 必须交给 `t.check(...)`，在评估用例收尾时统一求值。

计分制 `defineScoreEval` 使用 `ScoreTestContext`：用 `t.score(label, fact, { max })` 或 `t.score(label, { earned })` 记分，`test` 正常返回时自动收尾。没有 score use 时得到 0 分。Judge recipe 也是 ScoreFact producer，使用同一套 `check`、`require` 和 `score`。完整规则见[计分制](/zh/tutorials/evaluation-kinds#走完三步也要记三分)。全部成员：

## Judge ScoreFact

先在 `defineEval` 或 `defineScoreEval` 声明 `judge: true`，再创建并消费 Judge Fact：

```ts
const turn = await t.send("总结需求。");
const factual = turn.judge.autoevals.factuality(expected);
const quality = turn.judge.autoevals.closedQA(question);
const summary = turn.judge.autoevals.summarizes(sourceText);

t.check((factual).atLeast(0.8));
t.check((quality).atLeast(0.7));
t.check((summary).atLeast(0.75));
```

`t.judge.autoevals` 的根级 recipe 额外接收 `{ input, output }` 字符串材料。`turn.judge` 已绑定 immutable Turn 材料。模型配置按 Eval、Experiment、项目配置解析一次；没有单次模型覆盖或 `{ on }` 选项。

## 测试集导出

```ts
export default rows.map((row) =>
  defineEval({
    description: row.task,
    async test(t) {
      await t.send(row.prompt);
    },
  }),
);
```

数组导出会生成稳定 ID：`file/0000`、`file/0001` 等。

已有稳定业务 key 时也可以默认导出 `Record<string, EvalDef>`。例如 key `15193` 在 `swelancer.eval.ts` 中生成 `swelancer/15193`。key 必须是非空单一路径片段，不能是 `.` / `..`，不能含 `/`、`\\` 或控制字符。发现顺序按 key 字典序固定。
