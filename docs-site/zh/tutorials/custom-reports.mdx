title: "编写自定义报告"
description: "用普通 TypeScript 函数计算结果，并同时生成终端与网页报告。"
---

自定义报告接收宿主选好的 Sample，返回组件树：

```text
Sample
  → 普通 TypeScript 函数
  → 可序列化结果值
  → 组件
  → text / web
```

计算发生在 page render 中。
组件只显示 `rows`、`points`、`items`、`nodes` 或 `attempt` 等具体值。

## 创建第一份报告

新建 `reports/quality.tsx`：

```tsx
import {
  Page,
  Scatter,
  Table,
  agent,
  aggregate,
  costUSD,
  defineReport,
  passRate,
} from "niceeval/report";

export default defineReport(async (sample) => {
  const performance = await aggregate(sample, {
    by: { agent },
    values: { passRate, costUSD },
  });

  return (
    <Col>
      <Scatter
        points={performance}
        x="costUSD"
        y="passRate"
        point="agent"
      />
      <Table rows={performance} />
    </Col>
  );
});
```

运行：

```bash
niceeval show --report ./reports/quality.tsx
niceeval view --report ./reports/quality.tsx
```

两个宿主执行同一个 page render。
同一棵结果树分别交给 text 和 web renderer。

## 设成项目默认

在 `niceeval.config.ts` 中直接导入定义：

```ts
import { defineConfig } from "niceeval";
import quality from "./reports/quality";

export default defineConfig({
  report: quality,
});
```

以后直接运行 `niceeval show` 或 `niceeval view`。
临时切回内建报告时使用 `--report standard`。

## 收窄 Sample

宿主先处理 `--record`、`--exp`、评估位置参数和 `--fresh`，
再把 Sample 交给报告。

报告内继续使用 Sample 方法：

```ts
const security = sample.scope({ evals: "security/" });

const reliable = security.filter((attempt) =>
  attempt.result.verdict !== "errored"
);
```

`scope()` 改变比较总体和 coverage 分母。
`filter()` 删除不可信或不适用的观测。

一组图共享范围时，先生成一个具名 Sample：

```ts
const production = sample
  .scope({ experiments: "production/" })
  .filter(isReliableAttempt);
```

然后把同一个 `production` 传给每次计算。

## 使用 `aggregate()`

`aggregate()` 接收分组函数和 Calculation：

```tsx
const rows = await aggregate(sample, {
  by: {
    experiment,
    agent,
  },
  values: {
    passRate,
    costUSD,
  },
});
```

对象键就是结果字段名。
每个读数字段是 MetricValue，包含 value、unit、samples、total、basis 与 refs。

结果是普通数组，可以继续使用 JavaScript：

```ts
const ranked = rows
  .toSorted((a, b) =>
    (b.passRate.value ?? -Infinity) -
    (a.passRate.value ?? -Infinity)
  )
  .slice(0, 10);
```

不要把聚合结果再次传给 `aggregate()`。
需要增加读数时，回到同一份 Sample，把 Calculation 加进原来的 `values`。

## 定义自己的 Calculation

`rollup()` 把单 Attempt 取值函数变成 Calculation：

```ts
import {
  mean,
  min,
  rollup,
} from "niceeval/report";

export const changedLines = rollup(
  async (attempt) => {
    if (attempt.result.verdict !== "passed") {
      return null;
    }

    const diff = await attempt.diff();
    return diff ? countChangedLines(diff) : null;
  },
  {
    withinEval: min,
    acrossEvals: mean,
    unit: "lines",
    better: "lower",
  },
);
```

官方 Calculation 和用户 Calculation 使用同一个 `rollup()`。
空集合保持 `null`，不会被伪装成零。

## 显示实体列表

Sample 已经提供物化后的 `attempts`：

```tsx
export default defineReport((sample) => {
  const failures = sample
    .filter((attempt) =>
      attempt.result.verdict === "failed" ||
      attempt.result.verdict === "errored"
    )
    .attempts
    .toSorted((a, b) =>
      (attemptCostUSD(b.result) ?? 0) -
      (attemptCostUSD(a.result) ?? 0)
    )
    .slice(0, 50);

  return <AttemptList attempts={failures} />;
});
```

需要通用表格时先立即转换：

```tsx
const rows = toAttemptRows(failures);
return <Table rows={rows} />;
```

## 复用动态区块

复用就是普通函数：

```tsx
export async function overview(sample: Sample) {
  const performance = await aggregate(sample, {
    by: { agent },
    values: { passRate, costUSD },
  });

  return (
    <>
      <Scatter
        points={performance}
        x="costUSD"
        y="passRate"
        point="agent"
      />
      <Table rows={performance} />
    </>
  );
}
```

在 page render 中直接调用：

```tsx
render: async (sample) => (
  <Col>
    {await overview(sample)}
  </Col>
)
```

多个独立计算使用普通 `Promise.all()`。

## 创建多页报告

```tsx
export default defineReport({
  title: "Team evals",
  pages: [
    {
      id: "overview",
      title: "Overview",
      render: async (sample) => (
        <Col>
          {await overview(sample)}
        </Col>
      ),
    },
    {
      id: "failures",
      title: "Failures",
      render: failuresPage,
    },
    standardAttemptPage,
  ],
});
```

`pages` 的数组顺序就是导航顺序。
宿主只执行当前请求的 page。
`standardAttemptPage` 提供官方 Attempt 详情与 locator 下钻。

## 自定义 Attempt 详情

```tsx
{
  id: "attempt",
  title: "Attempt",
  input: "attempt",
  navigation: false,
  render: async (attempt) => {
    const [turns, files] = await Promise.all([
      toConversationTurns(attempt),
      toDiffFiles(attempt),
    ]);

    return (
      <Col>
        <Conversation turns={turns} />
        <DiffView files={files} />
      </Col>
    );
  },
}
```

一份报告最多有一张 Attempt page。
没有这张 page 时，locator 只显示为文本。

## 接入外部业务快照

先把外部数据写成冻结快照模块：

```tsx
// budget-snapshot.ts —— 运行前由脚本生成，随报告进版本库
export const budgets = {
  checkout: { monthlyUSD: 40 },
  search: { monthlyUSD: 25 },
};
```

报告文件直接 import：

```tsx
import { budgets } from "./budget-snapshot";

export default defineReport(async (sample) => {
  const performance = await aggregate(sample, {
    by: { experiment },
    values: { passRate, costUSD },
  });

  return <Table rows={joinBudgets(performance, budgets)} />;
});
```

page render 不请求网络，不读取环境变量、时钟或随机数。要更新数据，就重新生成快照模块。
快照属于报告的 import 图，开发服务器会在它变化时重新构建报告。

## 编写新的显示形状

现有组件组合不出目标显示时，使用扩展入口：

```tsx
import { defineRenderer } from "niceeval/report/extension";

const ConfusionMatrix = defineRenderer({
  text(value, options, context) {
    return renderTextMatrix(value, options, context);
  },
  web(value, options, context) {
    return <WebMatrix value={value} options={options} />;
  },
});
```

两个 renderer 都只接已经计算好的普通值。
自定义计算继续写普通函数，不需要注册协议。

## 钉住某个值的颜色

在报告外壳的 `dimensionPins` 中按分组字段和完整值固定视觉身份。
例如可以让同一个 Agent 在每一页都使用同一组颜色、线型和符号。

显示标签不是身份键。不要截 Experiment 路径末段，也不要按数组下标分配颜色。
完整主题字段见[报告主题](/zh/tutorials/theming)。

## 让自己的组件跟随任何主题

自定义 renderer 使用 `--niceeval-*` 主题令牌，
不要把 Basalt 或 Chalk 的 hex 值复制进组件。
状态使用 positive、negative、warning 等语义令牌，
名义 series 使用运行时分配的视觉身份。

## 嵌入自己的 React 页面

在服务端或构建进程中计算：

```ts
const points = await aggregate(sample, {
  by: { agent },
  values: { passRate, costUSD },
});
```

在浏览器使用 `niceeval/report/react`：

```tsx
<Scatter
  points={points}
  x="costUSD"
  y="passRate"
  point="agent"
/>
```

React 入口不读取 Record、Sample 或 artifact。
记录根不在产品运行环境时，把 Result 在构建期写成 JSON。
