`niceeval show` 在终端读取报告的 text 面，`niceeval view` 在浏览器读取同一份报告的 web 面。
两个入口装载同一个 `defineReport(...)` 产物，也使用同一份 Sample、数据源和证据引用。

报告作者只需要区分三个概念：

| 概念 | 负责什么 |
| --- | --- |
| Source | 从 Sample 或 AttemptEvidence 计算可序列化 Content |
| Composition | 读取当前 page input，协调多个 Source，再装配组件树 |
| Component | 把一份 Content 同步显示成 text 与 web |

数据读取、聚合和排序只在 Source 中发生。Component 的两个 renderer 都消费同一份 Content，
不会各自读取记录或重新计算指标。

## 从默认报告开始

NiceEval 自带的 `standard` 也是一份普通报告。它包含报告、Attempts、追踪三张导航页，
以及一张按 Attempt 定位符打开的详情页：

```tsx
import { defineReport } from "niceeval/report";
import { standard } from "niceeval/report/built-in";

export default defineReport({
  extends: standard,
  title: "Memory Evals",
  links: [{ label: "GitHub", href: "https://github.com/you/repo" }],
});
```

只改标题、链接、主题或统计脚本时，使用 `extends` 保留默认 pages。需要改变页面内容时，
直接用公开 Source、Composition 和 Component 重新声明 pages。

默认首页的组合组件是 `SampleOverview`：

```tsx
import { SampleOverview, defineReport } from "niceeval/report";

export default defineReport(<SampleOverview />);
```

## 创建第一份报告

报告文件使用 `.tsx`，项目需要安装 `react`，并把 `tsconfig.json` 的
`compilerOptions.jsx` 设为 `"react-jsx"`。

下面的报告用一份 Dataset 同时画质量成本图，并把 Experiment 事实列成表：

```tsx
// reports/quality-cost.tsx
import {
  Chart,
  Col,
  Series,
  Section,
  Table,
  costUSD,
  defineReport,
  passRate,
  sources,
} from "niceeval/report";

const qualityCost = sources.measure.rows({
  dimensions: ["experiment", "agent"],
  measures: [costUSD, passRate],
});

export default defineReport(
  <Col>
    <Section title="质量与成本">
      <Chart source={qualityCost} x="costUSD" y="passRate" legend tooltip>
        <Series id="frontier" mark="scatter" points="experiment" by="agent" />
      </Chart>
    </Section>
    <Table source={sources.entity.experiments} filter />
  </Col>,
);
```

```bash
niceeval show --report reports/quality-cost.tsx
niceeval view --report reports/quality-cost.tsx
```

宿主先按 `--record`、`--exp`、评估用例位置参数与 `--fresh` 选择 Sample，再解析报告。
同一 page 内，相同 Source 对象与相同 input 引用只计算一次。

## 直接绑定 Source

Source 是计算声明，Content 是计算结果。原语接收互斥的两种数据形态：

```tsx
// 让报告管线计算
<Table source={sources.entity.experiments} />

// 使用已经算好的 Content
<Table data={content} />
```

`source` 形态省略 `input` 时使用当前 page input。`data` 形态不会再读取或聚合数据。
同时传入 `source` 和 `data` 会报错。

需要配置的数据源先创建一个具名值。多个组件引用同一个值即可共享计算：

```tsx
const byAgent = sources.measure.rows({
  dimensions: ["agent"],
  measures: [passRate, costUSD],
});

export default defineReport(
  <Col>
    <Table source={byAgent} />
    <Chart source={byAgent} x="costUSD" y="passRate">
      <Series id="agents" mark="scatter" points="agent" />
    </Chart>
  </Col>,
);
```

分别调用两次 `sources.measure.rows(...)` 会创建两个 Source。即使配置相同，它们也会分别计算。

## 用 Composition 加工数据

需要过滤、截断、连接多个 Source 或动态生成组件树时，使用 `defineComposition`。
在 Composition 内通过 `ctx.resolve()` 取数，不能直接调用 `source.compute()`：

```tsx
import { Table, defineComposition, sources } from "niceeval/report";

export const CostliestAttempts = defineComposition(
  async ({ limit = 10 }: { limit?: number }, ctx) => {
    const content = await ctx.resolve(sources.entity.attempts);
    const rows = [...content.rows]
      .sort((a, b) => (b.costUSD ?? -Infinity) - (a.costUSD ?? -Infinity))
      .slice(0, limit);

    return <Table data={{ ...content, rows }} filter />;
  },
);
```

`ctx.resolve(source)` 默认使用 `ctx.input`。组合组件显式接收另一个同类型 input 时，
使用 `ctx.resolve(source, input)`；第二个参数只影响这次 Source 计算，不改变 page input。

```tsx
const PrefixSummary = defineComposition(
  async ({ input }: { input?: Sample }, ctx) => {
    const selected = input ?? ctx.input;
    const snapshot = await ctx.resolve(sources.sample.snapshot, selected);
    return <Callouts data={notices.sample(snapshot)} />;
  },
);
```

Composition 自己没有 renderer。它返回的每个可见节点仍必须是有 text/web 两面的 Component。

## 定义自己的 Source

需要复用一段 NiceEval 数据计算时，用 `defineSource`：

```tsx
import {
  defineSource,
  type Row,
  type Sample,
  type TableContent,
} from "niceeval/report";

interface BudgetRow extends Row {
  cells: {
    agent: { kind: "text"; text: string };
    spend: { kind: "number"; value: number | null; unit: "USD" };
  };
}

export const budgets = defineSource<Sample, TableContent<BudgetRow>>({
  name: "budgets",
  async compute(sample) {
    const totals = await computeBudgetByAgent(sample);
    return {
      columns: [{ key: "agent" }, { key: "spend", unit: "USD", better: "lower" }],
      rows: totals.map(({ agent, spend }) => ({
        key: agent,
        cells: {
          agent: { kind: "text", text: agent },
          spend: { kind: "number", value: spend, unit: "USD" },
        },
      })),
    };
  },
});
```

Source 可以读取 Sample、AttemptEvidence 和其中的 artifact 句柄，但返回的 Content 必须可序列化。
外部 API 数据先在报告运行前冻结成 JSON，再从 Composition 的 `ctx.data` 读取。

## 定义自己的双面 Component

内建原语表达不了新的视觉形状时，使用 `defineComponent`。Component 不提供异步取数面；
`dimensions`、`text` 和 `web` 都是同步纯函数：

```tsx
import { defineComponent, padEnd, stringWidth } from "niceeval/report";

interface BarData {
  rows: readonly { key: string; ratio: number | null; display: string }[];
}

export const PassBars = defineComponent<BarData, {}>({
  dimensions: (data) => ({
    agents: {
      dimension: "agent",
      encoding: { kind: "label" },
      values: data.rows.map((row) => row.key),
    },
  }),
  text(data, _options, ctx) {
    const agents = ctx.dimension("agents");
    const width = Math.max(...data.rows.map((_, index) => stringWidth(agents.at(index).label)));
    return data.rows
      .map((row, index) => {
        const label = agents.at(index).label;
        return `${padEnd(label, width)}  ${row.ratio === null ? "—" : row.display}`;
      })
      .join("\n");
  },
  web(data, _options, ctx) {
    const agents = ctx.dimension("agents");
    return (
      <ul className="acme-passbars">
        {data.rows.map((row, index) => (
          <li key={row.key}>
            <span>{agents.at(index).label}</span>
            <b>{row.ratio === null ? "—" : row.display}</b>
          </li>
        ))}
      </ul>
    );
  },
  styles: [{
    inline: `
      .acme-passbars { color: var(--niceeval-color-text); }
      .acme-passbars b { color: var(--niceeval-color-accent); }
    `,
  }],
});
```

不消费任何维度的组件也必须显式写 `dimensions: () => ({})`。renderer 只能读取传入的 data、
options 和呈现 context；不能读取 Sample、Record、磁盘或网络。

需要计算 `PassBars` 的数据时，把 Source 与 Component 放进 Composition：

```tsx
const PassBarsSection = defineComposition(async (_props: {}, ctx) => {
  const source = sources.measure.rows({
    dimensions: ["agent"],
    measures: [passRate],
  });
  const dataset = await ctx.resolve(source);
  return <PassBars data={toBarData(dataset)} />;
});
```

## 设成项目默认

报告定型后，把 `defineReport` 产物填进 `niceeval.config.ts` 的 `report` 字段：

```ts
import { defineConfig } from "niceeval";
import report from "./reports/quality-cost.tsx";

export default defineConfig({ report });
```

裸 `niceeval show` 和 `niceeval view` 会装载这份报告。临时回到内建报告时使用
`--report standard`。

## 钉住某个值的颜色

页级分配会保证同一页里的同一个维度值使用同一个视觉身份。需要跨页或跨周固定槽位时，
在报告外壳声明 `dimensionPins`：

```tsx
export default defineReport({
  title: "MemoryBench",
  dimensionPins: {
    memory: {
      baseline: 3,
      mempal: 1,
      nowledge: 5,
    },
  },
  pages: [
    { id: "report", title: "报告", content: <SampleOverview /> },
  ],
});
```

槽位范围是 1 到 24，钉住的是完整颜色加形状身份，不是某个 hex 颜色。

## 让自己的组件跟随任何主题

自定义组件使用 `--niceeval-*` CSS 令牌，不写死颜色：

```css
.acme-panel {
  background: var(--niceeval-color-surface);
  border: 1px solid var(--niceeval-color-border);
  border-radius: var(--niceeval-radius);
  color: var(--niceeval-color-text);
}
```

状态使用 `--niceeval-color-positive`、`--niceeval-color-negative` 与
`--niceeval-color-warning`。维度身份通过 `ctx.dimension(handle).at(index)` 获取，
不要按数组下标自行分配颜色。

## 嵌入自己的 React 页面

自己的 React 页面没有 report resolve。先在服务端计算 Content，再把它传给
`niceeval/report/react` 的纯 web 原语：

```tsx
import { openRecord } from "niceeval/record";
import { currentSample } from "niceeval/sample";
import { passRate, sources } from "niceeval/report";
import { Table } from "niceeval/report/react";

export default async function EvalsPage() {
  const record = await openRecord(".niceeval");
  const sample = currentSample(record);
  const source = sources.measure.rows({
    dimensions: ["experiment"],
    measures: [passRate],
  });
  const data = await source.compute(sample);
  return <Table data={data} />;
}
```

这里直接调用 `compute()` 是正确的，因为代码不在 page 管线里，也没有 `ctx.resolve()`。

## 发布静态报告

```bash
niceeval view --report reports/quality-cost.tsx --out site
```

导出结果包含报告 pages 和可达的 Attempt 证据。初始 HTML 不依赖 JavaScript；
排序、过滤、tooltip 和 dialog 只做渐进增强，不改变 Source 计算出的 Content。
