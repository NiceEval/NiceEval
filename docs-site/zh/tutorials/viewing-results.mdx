运行结束后，先从停稳的 Record 选择要看的 Run。`show` 在终端显示结果，`view` 在本机显示网页。两条命令使用同一条数据路径：

```text
Record reader → Sample → ReportInput → show 或 view
```

Sample 决定比较范围和分母；ReportInput 带着 Sample 的状态、已请求通道和完整度进入 Report。Report 不直接读取文件。

## 选择要看的 Run

选择一个明确 Run：

```sh
npx niceeval show --run 01J9ZK3M6P4T7V9X2C5N8QW0RY
```

也可以选择每个 Experiment 最后完成的 Run：

```sh
npx niceeval show --latest --experiment checkout
```

`latest` 只考虑已完成的 Run。需要查看未完成 Run 时，使用完整 `--run` ID。

## 在终端查看

`show` 呈现默认 Report 的文字内容。指定页面或 Report 时，命令仍从同一份 Sample 建立 `ReportInput`。

```sh
npx niceeval show --run 01J9ZK3M6P4T7V9X2C5N8QW0RY --page overview
npx niceeval show --latest --experiment checkout --json
```

`--json` 输出已计算的页面数据与状态，不会建立另一套取数路径。需要查看某个 Attempt 时，使用完整 locator：

```sh
npx niceeval show --run 01J9ZK3M6P4T7V9X2C5N8QW0RY --page attempt-01J8ZK3M6P4T7V9X2C5N8QW0RY
```

## 在浏览器查看

```sh
npx niceeval view --latest --experiment checkout --no-open
```

本机页面服务一次固定的 `ReportInput`。页面不会因后续文件编辑自行改变。修改 Record 或 Report 后，结束这次命令并重新执行 `view`。

## 读懂分母与通道状态

Sample 保留 Run 的完整 expected-slot 分母。一个 slot 可能是：

| 状态 | 含义 |
| --- | --- |
| `included` | 有合法 Member 与可读取的 Attempt。 |
| `not-recorded` | 计划中的 slot 没有 Member。 |
| `invalid` | Member、Attempt 或核心引用有问题。 |
| `excluded` | 本次选择排除了该项。 |

页面与 Calculation 还会显示所请求通道的状态。`unavailable` 表示未采集或不适用；`unsupported` 表示 reader 不支持该通道；`invalid` 会显示具名问题并使依赖它的请求失败。partial 读数必须带实际观察数量、分母和 partial 标记。

## 编辑后重新读取

Record 是可编辑的当前数据集。目录停稳后，用户可以修改 Verdict、Usage 或其他通道值。完成修改后，重新运行 `show` 或 `view`；新的 Sample 会使用当前值。

不要让 Runner、active reader、导出的 Sample 选择 / ReportInput 构造阶段与人工编辑同时操作同一目录。reader 释放后，Report 执行和写站不再访问 Record，可以继续完成。
